Урок превращает статичный прототип в живое приложение, вызывающее реальные AI-сервисы: разбираются понятия API и подключение моделей через AI IDE.

- Суть API: отправить запрос и получить результат в том же формате
- Безопасность API Key: не публиковать и не коммитить в Git
- Подключение DeepSeek (текст), Qwen3 VL (изображение→текст), Seedream (генерация)
- OpenAI-совместимый интерфейс: переключение через смену ключа, URL и имени модели

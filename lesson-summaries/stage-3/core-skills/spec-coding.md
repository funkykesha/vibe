Урок знакомит с парадигмой Spec Coding (доклад Шона Грова «The New Code»): код — потеря при проекции намерения, а настоящий «новый код» — спецификация.

- Философия «всё есть Markdown»: CLAUDE.md, rules/, specs/ как живая спецификация.
- Спецификация — единственный источник истины; AI-код лишь черновик, проверка обязательна.
- Vibe Coding и Spec Coding дополняют друг друга: прототип против продакшена.
- Цикл `/plan`: Specify → Plan → Tasks → Implement, версионирование в Git.

# Удалённая разработка с Claude Code на телефоне

> Этап 3 · Ключевые навыки

## О чём урок
Урок показывает, как превратить телефон в «карманного помощника разработки» с Claude Code. Главная идея всех решений — архитектура тонкого клиента: телефон выступает лишь пультом управления, а настоящая работа выполняется на хосте или в облаке. Рассмотрены семь способов с разбором их плюсов, минусов и сценариев применения.

## Ключевые темы
- Почему мобильная разработка — проблема: ограничения ввода, экрана, окружения и нестабильность сети; решение через архитектуру тонкого клиента.
- Способ 1 — официальное iOS-приложение: облачное выполнение через Anthropic, синхронизация с GitHub (недоступно в материковом Китае).
- Способ 2 — Happy Coder: открытый клиент с e2e-шифрованием через сервер-ретранслятор; простая настройка, но возможны обрывы.
- Способ 3 — HAPI: локально-ориентированный, WireGuard + TLS, самостоятельный ретранслятор, мультимодельность, голосовое управление, AFK-аппрув.
- Способ 4 — SSH + Tailscale + Tmux: самый полнофункциональный для профессионалов; Tailscale решает проблему NAT, Tmux сохраняет сессию.
- Способы 5-7: Termux (локально на Android), Claude Code UI (веб-интерфейс), облачное окружение (Sealos DevBox и др.).
- Безопасность: риски серверов-ретрансляторов, градация чувствительности кода, управление ключами, sandbox, самостоятельный ретранслятор (Headscale).

## Главные выводы
- Телефон — это только пульт; тяжёлые вычисления выполняются на хосте или в облаке.
- Большинство современных решений не требуют проброса портов благодаря режиму ретрансляции (обе стороны подключаются исходящими соединениями).
- Для пользователей из материкового Китая рекомендован Happy Coder с настройкой внутреннего API-прокси.
- Чем чувствительнее код, тем строже выбор: для коммерческого кода — только SSH + Tailscale без сторонних ретрансляторов.

## Инструменты и технологии
- Claude Code, официальное iOS-приложение, Happy Coder, HAPI
- SSH, Tailscale / Headscale, Tmux, MOSH, Termux, ngrok
- Claude Code UI (CloudCLI), Sealos DevBox, GitHub Codespaces, Gitpod

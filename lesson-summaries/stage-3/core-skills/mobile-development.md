# Удалённая разработка с Claude Code на телефоне

> Этап 3 · Ключевые навыки

<!-- nav -->
**📚 Версии:** **Кратко** · [Расширенно](../../../lesson-summaries-full/stage-3/core-skills/mobile-development.md) · [Полный перевод](../../../lesson-originals-ru/stage-3/core-skills/mobile-development.md) · [Оригинал 中文](https://github.com/datawhalechina/easy-vibe/blob/main/docs/zh-cn/stage-3/core-skills/mobile-development/index.md)

Урок показывает, как превратить телефон в карманного помощника разработки. Главная идея — архитектура тонкого клиента: телефон лишь пульт, работа идёт на хосте или в облаке.

- Семь способов: iOS-приложение, Happy Coder, HAPI, SSH + Tailscale + Tmux, Termux и др.
- Большинство решений не требуют проброса портов благодаря режиму ретрансляции.
- Безопасность: чем чувствительнее код, тем строже выбор.
- Для коммерческого кода — только SSH + Tailscale без сторонних ретрансляторов.

# Быстрый старт с Claude Code: основное руководство

> Этап 3 · Ключевые навыки

Claude Code — официальный AI-инструмент Anthropic в терминале, понимающий контекст всего проекта. Урок ведёт от установки до уверенного владения базовыми приёмами и конфигурацией.

- Установка через npm (Node.js 18+), инициализация и вход в аккаунт.
- Приёмы: двойной Esc, `@`, `!`, slash-команды (`/plan`, `/init`, `/compact`), Shift+Tab.
- Конфигурация: `CLAUDE.md`, `.claudeignore`, `settings.json`, права доступа.
- Откат двойным Esc касается диалога, не файлов — для кода нужен Git.

# Быстрый старт с Claude Code: основное руководство

> Этап 3 · Ключевые навыки

## О чём урок
Claude Code — официальный AI-инструмент Anthropic, интегрирующий большую языковую модель прямо в терминал. В отличие от обычного автодополнения, он понимает контекст всего проекта и выполняет сложные задачи: от генерации и рефакторинга кода до отладки и написания документации. Урок проводит от установки до уверенного владения базовыми приёмами, конфигурацией и командами.

## Ключевые темы
- Установка через npm (`npm install -g @anthropic-ai/claude-code`, Node.js 18+) или силами самого AI-агента, первичная инициализация и вход в аккаунт.
- Три вводных эксперимента: диалог, генерация Markdown-документа, написание и запуск игры — демонстрация понимания, генерации и выполнения кода.
- Основные приёмы: двойной Esc (откат диалога), `@` (ссылки на файлы), `!` (запуск команд), `/plan`, `/init`, `/compact`, `/context`, `/resume`, Shift+Tab (авто-принятие), Ctrl+C.
- Конфигурация: иерархия `settings.json` / `settings.local.json`, файл `CLAUDE.md` («память проекта»), `.claudeignore`, настройка прав (`permissions`: allow/ask/deny), модульный каталог `rules/`.
- Команды и символы: справочник slash-команд, работа с файлами, Git, кодом и тестами, цепочки операций.

## Главные выводы
- `CLAUDE.md` — ключевой файл: Claude читает его при запуске и сразу понимает стек, команды и стандарты проекта.
- Откат двойным Esc касается только диалога, но не изменений в файлах — для отката кода нужен Git (`git checkout`/`reset`), поэтому фиксируйте состояние перед рискованными операциями.
- Грамотный `.claudeignore` и периодический `/compact` снижают расход токенов (нередко на 40-60%).
- Для китайских пользователей описана работа через сторонние API-прокси (`ANTHROPIC_BASE_URL`, `ANTHROPIC_API_KEY`).

## Инструменты и технологии
- Claude Code CLI, Node.js, npm
- CLAUDE.md, .claudeignore, settings.json, каталог rules/
- Slash-команды (/init, /plan, /compact, /context, /cost, /permissions), Git, плагины (commit-commands)

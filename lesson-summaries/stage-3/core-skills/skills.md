# Полное руководство по Claude Code Skills

> Этап 3 · Ключевые навыки

Skills упаковывают экспертные знания и процессы в переиспользуемые пакеты: один раз определил навык — Claude работает по стандарту. Урок ведёт от установки до устройства.

- Структура SKILL.md: YAML frontmatter + Markdown; глобальные и проектные навыки.
- Трёхуровневая загрузка экономит токены: метаданные → инструкции → ресурсы.
- Skills — знания («как делать»), MCP — инструменты («чем делать»).
- Качество `description` критично; повторил инструкцию дважды — создай Skill.

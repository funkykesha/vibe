# Как создать WeChat-мини-программу с бэкендом

> Этап 3 · Кроссплатформенная разработка

Переход от фронтенд-онли мини-программы к полноценному продукту с сервером через WeChat Cloud Development (CloudBase).

- Фронтенд — вход, бэкенд — судья: ключи, права, суммы и правила только на сервере.
- Три маршрута: A — облачная разработка (по умолчанию), B — облачный хостинг, C — свой бэкенд.
- Платежи: оформление и подпись на сервере, статус — по серверному коллбэку.
- Безопасность по умолчанию: запрет на всё, затем минимально нужные права.

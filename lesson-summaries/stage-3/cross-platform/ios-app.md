# Как создать iOS-приложение — нативная разработка на SwiftUI

> Этап 3 · Кроссплатформенная разработка

Полный цикл создания нативного iOS-приложения «Холодильный шеф» (FridgeChef) на Swift / SwiftUI с генерацией рецептов через AI API.

- Поток: HTML-прототип → перенос в SwiftUI → бизнес-логика и Core Data.
- Инструменты: Xcode, Trae, SiliconFlow (OpenAI-совместимый API), Core Data.
- Для отладки на устройстве хватит личного Apple ID; платный аккаунт ($99/год) только для App Store.
- Типовые ошибки устройства связаны с подписью, сопряжением и доверием, а не с кодом.

# Как создать iOS-приложение — нативная разработка на SwiftUI

> Этап 3 · Кроссплатформенная разработка

## О чём урок
Урок проводит полный цикл создания нативного iOS-приложения — от идеи до запуска на реальном iPhone. На примере приложения «Холодильный шеф» (FridgeChef), которое по введённым продуктам генерирует рецепт через настоящий AI API, показана нативная разработка на Swift / SwiftUI с AI-ассистентом Trae.

## Ключевые темы
- Требования: Mac с актуальной macOS, iPhone с включённым режимом разработчика, Xcode, Trae, Apple ID.
- Создание проекта в Xcode: шаблон App, выбор Core Data для хранения, запуск в симуляторе.
- Поэтапный подход к разработке: сначала требования (REQUIREMENTS.md), затем HTML+Tailwind прототип (стиль Neo-Pop), затем перенос в SwiftUI, подключение AI API, локальное хранение, иконка.
- Подключение AI: SiliconFlow (硅基流动) с OpenAI-совместимым API, APIService.swift, парсинг JSON в RecipeModel.
- Core Data: ручная настройка Entity в Xcode, затем генерация логики AI; FetchRequest для истории.
- Запуск на реальном устройстве и типовые ошибки: проблемы подписи, сопряжения устройства, «недоверенный разработчик», публикация в App Store.

## Главные выводы
- Эффективный поток: HTML-прототип для быстрой проверки структуры → перенос в SwiftUI → бизнес-логика и данные.
- При любой ошибке достаточно скопировать полный текст ошибки в Trae — он отладит с учётом контекста проекта.
- Для отладки на устройстве достаточно личного Apple ID; платная Apple Developer Program ($99/год) нужна только для публикации в App Store.
- Типовые ошибки реального устройства связаны не с кодом, а с подписью, сопряжением и доверием.

## Инструменты и технологии
- Swift, SwiftUI, Xcode, Core Data, симулятор iOS.
- Trae (Vibe Coding), HTML + Tailwind CSS (прототип), Lovart (иконка).
- SiliconFlow (OpenAI-совместимый API), App Store Connect, Apple Developer Program.

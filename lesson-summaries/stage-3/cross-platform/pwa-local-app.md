# Как разработать локальное PWA-приложение — превратить веб-страницу в «настоящее приложение»

> Этап 3 · Кроссплатформенная разработка

## О чём урок
Урок показывает, как из обычного веб-проекта сделать PWA — приложение, устанавливаемое на рабочий стол и главный экран телефона, работающее офлайн. На примере «Помидорной фермы» (番茄农场) — сочетания техники Pomodoro и игры про выращивание овощей — React-приложение превращается в PWA и публикуется для установки на телефоне.

## Ключевые темы
- Что такое PWA: особая веб-страница, которая через Service Worker кэширует ресурсы и работает офлайн; сравнение с обычным сайтом и нативным приложением.
- Окружение: Node.js (18+), Vite, AI-ассистент (Cursor/Trae/Claude Code).
- Создание проекта: React + TypeScript через Vite, установка vite-plugin-pwa, иконки 192×192 и 512×512.
- Конфигурация PWA в vite.config.ts: manifest, registerType autoUpdate, display standalone, workbox.globPatterns для кэширования.
- Разработка: первая «общая команда» (Pomodoro, грядки, уровни, сохранение), затем SVG-культуры с анимацией и звуки.
- Локальное тестирование: build + preview (Service Worker работает только в продакшен-сборке), установка на ПК и проверка офлайн.
- Стратегии хранения данных: localStorage и его ограничения, облачная синхронизация (Supabase), экспорт/импорт, Chrome Storage Sync.
- Деплой на Vercel (HTTPS обязателен), установка на Android (Chrome) и iPhone (Safari), аудит через Lighthouse.

## Главные выводы
- PWA — одно из самых выгодных кроссплатформенных решений: одна кодовая база, мгновенная установка, авто-обновление, малый размер.
- Service Worker регистрируется только в продакшен-сборке, поэтому офлайн надо тестировать через build/preview.
- Ключевой принцип PWA — прогрессивное улучшение: сначала установка и офлайн, потом push, фоновая синхронизация и др.
- iOS имеет ограничения: установка только через Safari, push с iOS 16.4+, нет Background Sync.

## Инструменты и технологии
- React, TypeScript, Vite, vite-plugin-pwa, Service Worker, Web App Manifest, Workbox.
- localStorage, Supabase (облачная синхронизация), Vercel/Netlify/GitHub Pages, Lighthouse, PWA Builder.

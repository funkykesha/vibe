# Как создать собственный персональный сайт и научный блог: статический деплой на GitHub Pages

> Этап 3 · Личный бренд

## О чём урок
Урок проводит через полный замкнутый цикл создания персональной академической веб-страницы: от поиска готового шаблона до его превращения в личную страницу Илона Маска и бесплатной публикации в интернете. Главная идея в том, что благодаря подходу Vibe Coding больше не нужно вручную учить HTML/CSS — вы выступаете «главным редактором» сайта, а AI-помощник Trae пишет и правит код за вас. В качестве учебного примера наполнение делается для Маска, чтобы избежать страха за приватность, а в конце предлагается заменить данные на свои.

## Ключевые темы
- Что такое персональная академическая страница и зачем она нужна: «несгорающая визитка», «второй мозг», индексация в Google/Google Scholar.
- Четыре способа создания сайта: ручной код, визуальные конструкторы (Wix/WordPress), шаблоны на GitHub (генераторы статических сайтов), Vibe Coding по картинке. Урок выбирает связку GitHub Pages + академический шаблон + правки через AI.
- Подготовка окружения: Trae, аккаунт GitHub, Git, Ruby (для предпросмотра шаблона на Jekyll).
- От шаблона к первой рабочей странице: Fork репозитория, переименование в `username.github.io`, клонирование через Trae, локальный предпросмотр через `bundle install` и `jekyll serve`.
- AI-наполнение контентом: единый предварительный промпт-ограничение, замена личности, переопределение «публикаций» в «технические white papers», правка соцссылок и аватара.
- UI-кастомизация через AI без знания CSS (стиль «SpaceX Dashboard», цвета Tesla Red / «марсианский красный»).
- Деплой через GitHub Actions и обновление сайта (commit и push).
- Продвинутый уровень: написание сайта с нуля (один `index.html`) и его раздельный деплой через отдельный репозиторий.

## Главные выводы
- Основной маршрут запоминается как: Fork шаблона → AI-«ремонт» → push в онлайн.
- Vibe Coding меняет роль: человек задаёт тон и контент, AI делает «грязную работу» с кодом, GitHub Pages даёт бесплатный хостинг и адрес.
- Имя репозитория обязано быть `имя_пользователя.github.io` — иначе бесплатный домен не выдаётся.
- Чтобы перенести шаблон на себя, удобно сначала отформатировать резюме через ChatGPT/Gemini в Markdown, а затем отдать чистый текст в Trae.
- Главная ценность не в экономии времени на коде, а в том, что стирается стена между «идеей» и «реализацией» — ограничены только воображением и вкусом.

## Инструменты и технологии
- Trae — AI-редактор кода (основной инструмент Vibe Coding).
- GitHub и GitHub Pages — бесплатный хостинг и публичный URL.
- GitHub Actions — облачная сборка Jekyll-сайта.
- Git — доставка кода с локальной машины в облако.
- Ruby + Jekyll + Bundler — фреймворк шаблона и локальный предпросмотр (с китайским зеркалом gems.ruby-china.com).
- HTML/CSS/JS — для варианта «сайт с нуля».

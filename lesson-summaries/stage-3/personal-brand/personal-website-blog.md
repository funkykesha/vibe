# Как создать собственный персональный сайт и научный блог: статический деплой на GitHub Pages

> Этап 3 · Личный бренд

Полный цикл создания академической страницы через Vibe Coding: вы «главный редактор», а AI-помощник Trae пишет и правит код без знания HTML/CSS.

- Маршрут: Fork шаблона → AI-«ремонт» → push в онлайн.
- Имя репозитория обязано быть `username.github.io`.
- Окружение: Trae, GitHub, Git, Ruby + Jekyll для предпросмотра.
- AI-наполнение контентом и UI-кастомизация, деплой через GitHub Actions.

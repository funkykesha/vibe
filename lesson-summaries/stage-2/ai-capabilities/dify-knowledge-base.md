# Знакомство с Dify и интеграция базы знаний

> Этап 2 · AI-способности

## О чём урок
Урок показывает переход от простого чат-бота к AI-агентам и AI-рабочим процессам (workflow), приближенным к реальным бизнес-задачам. На практике учащиеся осваивают платформу Dify: создают чат-бота, собирают базу знаний на основе RAG, строят рабочий процесс с классификацией намерений и подключают созданного агента к фронтенду через API. Параллельно вводится AI IDE Trae как основной инструмент разработки вместо z.ai.

## Ключевые темы
- Почему чат-бот «только говорит, но не делает» и какие три способности превращают его в цифрового сотрудника: собственные знания, вызов инструментов, структурированное выполнение.
- RAG (Retrieval-Augmented Generation): извлечение релевантных фрагментов из базы знаний и подстановка их в контекст модели для борьбы с «галлюцинациями».
- Отличие AI-агента от AI-workflow: стабильное, воспроизводимое и масштабируемое выполнение задач по SOP вместо импровизации модели.
- Обзор low-code платформ: Dify, Coze, n8n, а также Baidu Qianfan, Alibaba Bailian, Tencent.
- Практика в Dify: создание Chatbot, настройка собственных провайдеров моделей (LLM, Embedding, Rerank), сборка базы знаний (чанкинг, overlap, Q&A-формат, Top K, Score Threshold), тест извлечения.
- Узлы и инструменты workflow: LLM, Knowledge Retrieval, Question Classifier, Condition, Iteration, Loop, Code, Template, HTTP Request и др.
- Построение рабочего процесса классификации намерений (сценарий ресторана), импорт/экспорт через DSL, запуск шаблона DeepResearch.
- Вызов Dify через API и сборка фронтенда чата в Trae; решение проблемы HTTP/HTTPS через прокси на Zeabur.

## Главные выводы
- Самый простой и востребованный агент — это бот вопросов-ответов на базе знаний; он делает ответы модели обоснованными, а не выдуманными.
- Workflow нужен там, где важны аудит, повторное использование и контроль; Chatflow подходит для диалога, Workflow — для автоматизации одноразовых задач.
- Low-code не значит «без обучения»: платформа добавляет промежуточный слой со своими правилами, который тоже нужно осваивать.
- Лучший способ освоить узлы и инструменты — импортировать готовые DSL-шаблоны и спрашивать модель по скриншотам, а не строить всё с нуля.

## Инструменты и технологии
- Dify — open-source LLMOps-платформа (Chatbot, Chatflow, Workflow, база знаний RAG, DSL, API).
- Coze, n8n и облачные платформы Baidu/Alibaba/Tencent — альтернативные low-code решения.
- Trae — AI IDE для разработки фронтенда и работы в режимах Chat / Builder with MCP.
- Модели и сервисы: GPT, Claude, Qwen, Kimi, GLM; SiliconFlow, OpenAI-API-compatible, Embedding/Rerank (Qwen, Jina), Tavily Search.
- Zeabur — деплой собственного Dify и HTTPS-прокси для обхода ограничения HTTP.

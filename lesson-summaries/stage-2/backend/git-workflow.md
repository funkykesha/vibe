# Рабочий процесс Git и GitHub

> Этап 2 · Бэкенд

Git хранит историю кода, GitHub — удалённый хостинг и совместная работа. Все операции можно делегировать AI-ассистенту, не запоминая команды.

- Установка и настройка Git, репозитории на GitHub (Issues, PR, README, `.gitignore`).
- SSH-ключи (`ed25519`) безопаснее HTTPS; приватный ключ никому не передавать.
- Базовые команды: `clone`, `pull`, `commit`, `push`.
- Указывай путь и имя репозитория, чтобы AI не запушил не туда.

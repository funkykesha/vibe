Создаём «живой магический портрет» персонажа: он общается и меняет выражение лица, связывая интерфейс, код, Dify-воркфлоу и публикацию.

- Реалистичность даёт база знаний Dify плюс стиль речи в системном промпте
- Эмоции «оживляют»: числовое значение настроения управляет сменой изображения
- Секреты (Dify API key) — только в переменных окружения, не в коде
- Деплой: загрузка на GitHub и публикация через Zeabur

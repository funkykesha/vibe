# Обновление интерфейса с помощью современных библиотек компонентов

- Ключевые библиотеки: Ant Design, shadcn/ui, HeroUI, Material UI
- Достаточно указать библиотеку в промпте — «бесплатный апгрейд» консистентности
- shadcn/ui: «владение кодом», исходники в проекте и правятся напрямую
- При проблемах — документация; ссылку на доку можно дать AI

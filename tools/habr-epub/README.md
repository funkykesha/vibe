# habr-epub

Сборщик EPUB из статей Хабра по epub-навигатору со ссылками.

Исходный навигатор (`hammingnavigator.epub`) — это оглавление русского перевода
книги Хэмминга «Искусство заниматься наукой и инженерным делом»: 32 блока
`<div class="item">` с названием главы и ссылкой на публикацию. Здесь скрипт
берёт из него структуру, скачивает тексты статей и собирает полноценный EPUB 3
с оглавлением.

## Запуск

```bash
python3 habr2epub.py hammingnavigator.epub -o hamming.epub
```

Зависимостей нет — только стандартная библиотека Python 3.9+. Скачивание идёт
с паузой в секунду между запросами; 32 главы с картинками занимают несколько
минут.

| Ключ | Что делает |
|---|---|
| `-o, --out` | Куда писать epub (по умолчанию `book.epub`) |
| `--cache-dir` | Кеш скачанного, по умолчанию `.habr-cache` |
| `--delay` | Пауза между запросами в секундах (по умолчанию 1) |
| `--limit N` | Собрать только первые N глав — удобно для проверки |
| `--no-images` | Не тянуть картинки (epub получается сильно легче) |
| `--offline` | Ничего не качать, брать только то, что уже в кеше |
| `--title/--author/--translator` | Метаданные книги |

Вместо epub-навигатора можно передать JSON — список объектов с полями
`section`, `label`, `title`, `blurb`, `url`.

## Что получается

- отдельный XHTML-файл на главу, порядок чтения сохранён;
- оглавление в двух формах: `nav.xhtml` (EPUB 3, с вложенностью по разделам
  навигатора) и `toc.ncx` (для старых читалок);
- картинки скачаны внутрь книги, ссылки переписаны на локальные;
- в конце каждой главы — ссылка на оригинальную публикацию.

Главы, которые скачать не удалось, попадают в книгу страницей-заглушкой со
ссылкой на оригинал, так что epub остаётся валидным. Повторный запуск с тем же
`--cache-dir` возьмёт скачанное из кеша и докачает только пропущенное.

## Как устроено

1. **Навигатор** (`NavigatorParser`) — вытаскивает разделы (`h2`) и главы
   (`div.item`: label, title, blurb, ссылка).
2. **Загрузка** (`Fetcher`) — кеш на диске по sha1 URL, троттлинг, три попытки
   с экспоненциальной паузой. Текст статьи берётся из публичного API
   (`/kek/v2/articles/<id>/`), при неудаче — парсингом страницы
   (`#post-content-body`, `.article-formatted-body`, `.post__text`).
3. **Санитайзер** (`Sanitizer`) — HTML Хабра в валидный XHTML: выбрасывает
   script/iframe/форму вместе с содержимым, разворачивает неизвестные теги,
   закрывает незакрытые `<p>` и `<li>`, экранирует текст, делает URL
   абсолютными, префиксует id, чтобы якоря глав не конфликтовали.
4. **Сборка** — zip с несжатым `mimetype` первым файлом, `content.opf`,
   `nav.xhtml`, `toc.ncx`, стилями и главами.

## Тесты

```bash
python3 test/test_habr2epub.py
# заодно проверить разбор реального навигатора:
NAVIGATOR_EPUB=path/to/hammingnavigator.epub python3 test/test_habr2epub.py
```

Сеть тестам не нужна: статьи-фикстуры отдаются через `file://`. Проверяются
разбор навигатора, санитайзер (валидность XML, вырезание скриптов, сущности,
таблицы, якоря) и сборка целиком — включая то, что манифест, spine и оглавление
ссылаются только на реально существующие в архиве файлы.

## Про права

Скрипт — инструмент для личного офлайн-чтения: он ходит по тем же публичным
страницам, что и браузер. Права на оригинал и перевод принадлежат авторам;
распространять собранный файл не стоит.

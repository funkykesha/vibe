# От прототипа дизайна к коду проекта

> Этап 2 · Фронтенд

## О чём урок
Урок показывает, как превратить готовый макет из Figma или MasterGo в работающий фронтенд-код. Разбираются три типовых пути перехода от прототипа к коду, их сильные и слабые стороны и рекомендации по выбору под конкретный проект.

## Ключевые темы
- Путь 1: мультимодальный AI восстанавливает код напрямую по скриншоту макета
- Путь 2: экспорт кода через собственные возможности платформы или плагины (Figma Make, плагины Figma to Code, Anima, Locofy)
- Путь 3: экспорт кода через MCP (Model Context Protocol)
- Типичные проблемы генерации (кривая раскладка, неточные цвета и шрифты) и их решения
- Работа с кодом после экспорта: локальный запуск, тестирование, доработка через AI IDE

## Главные выводы
- Мультимодальный AI — самый гибкий и простой путь, подходит для быстрой проверки идей; точность средняя
- Платформенные возможности (особенно Figma Make) дают высокую точность восстановления и редактируемость, но могут требовать Pro-доступа
- MCP даёт максимальную автоматизацию и точность: модель читает не скриншот, а исходную структуру и токены дизайна
- Рекомендуется новичкам начинать с пути 1, команде — путь 2, для эффективности — путь 3; пути можно комбинировать по стадиям проекта
- Полезный приём: сначала получить HTML, затем конвертировать в React в локальной IDE

## Инструменты и технологии
- Мультимодальные модели: Gemini, Qwen, Claude
- Figma Make, MasterGo AI, GitHub-интеграция
- Плагины: Figma to Code, Anima, Locofy
- MCP-серверы (Figma MCP Server, MasterGo MCP), Claude Code, Cline, Trae

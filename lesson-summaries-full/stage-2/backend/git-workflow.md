## О чём урок
Урок знакомит с системой контроля версий Git и платформой хостинга кода GitHub. Объясняется, как устанавливать и настраивать Git, создавать репозитории, настраивать SSH-аутентификацию и выполнять основные операции совместной работы. Особое внимание уделяется тому, как делать всё это с помощью AI-ассистента (например, Trae), не запоминая команды наизусть.

## Ключевые темы
- Установка Git на Windows, macOS и Linux, инициализация и настройка пользователя (`git config --global user.name`/`user.email`).
- Что такое GitHub: удалённое хранилище плюс инструменты совместной работы (Issues, Pull Requests, Projects) и крупнейшее open-source-сообщество (значимость метрики stars).
- Регистрация аккаунта и создание первого репозитория: имя, описание, видимость (private/public), README, `.gitignore` и лицензия.
- Привязка SSH-ключа: генерация пары ключей (`ssh-keygen -t ed25519`), загрузка публичного ключа в GitHub, проверка через `ssh -T git@github.com`.
- Базовые операции: `git clone`, `git pull`, `git commit`, `git push`.

## Главные выводы
- Контроль версий позволяет отслеживать изменения, создавать контрольные точки и свободно переключаться между версиями кода.
- SSH безопаснее и удобнее HTTPS: не нужно вводить пароль при каждой операции, аутентификация идёт по паре ключей. Приватный ключ нельзя никому передавать.
- Для каждого устройства генерируется отдельная пара ключей, привязанная к одному аккаунту.
- Все операции Git/GitHub можно делегировать AI-инструменту, чётко указывая путь и имя нужного репозитория, чтобы не запушить в неправильное место.

## Инструменты и технологии
- Git, GitHub
- SSH (ed25519), Git Bash, PowerShell
- Trae (AI-ассистент для выполнения команд), Homebrew, Xcode

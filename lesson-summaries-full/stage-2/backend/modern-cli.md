## О чём урок
Урок знакомит с AI-агентами программирования, работающими прямо в командной строке (CLI), в отличие от агентов, встроенных в AI-IDE вроде Trae или Cursor. Рассматриваются Claude Code, Codex и OpenCode, способы их установки и подключения к разным моделям через Anthropic-совместимые API, а также продвинутые приёмы использования.

## Ключевые темы
- Что такое CLI и почему текстовый интерфейс эффективнее GUI для разработки и работы с серверами.
- Отличия CLI-агентов от IDE-агентов: более длинный контекст, быстрее вызовы инструментов, поддержка большего числа моделей; сравнение Claude Code и Cursor.
- Claude Code: возможности (редактирование кода, фикс багов, тесты, Git-воркфлоу), команды (`claude`, `-p`, `-c`, `/init`, `/clear`, `/compact`, `/cost`, `/model`), файл `CLAUDE.md`, внутренний цикл «восприятие — мышление — действие — проверка».
- Подключение бэкендов через переменные окружения (`ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`): GLM, Kimi K2, MiniMax, DeepSeek,火山引擎 (Volcano Engine), Siliconflow, DashScope.
- Claude Code Router для маршрутизации запросов между моделями.
- Codex (OpenAI, GPT-5) и OpenCode (мультимодельный агент, бесплатные модели, плагин Oh-My-OpenAgent, MCP, `AGENTS.md`).
- Практические сценарии: написание PRD/«конкретизация требований», управление файлами, развёртывание open-source-проектов (Dify), объяснение кода.

## Главные выводы
- В современной практике vibe coding CLI-инструменты часто предпочтительнее встроенных в IDE агентов из-за стабильности, длинного контекста и гибкости.
- Прямое использование официального Claude Code дорого; выгоднее подключать совместимые API (например, месячный пакет GLM ~20 юаней).
- Стоит освоить несколько инструментов и переключаться между ними в зависимости от задачи; выбирать вариант с лучшим соотношением «качество/стоимость».
- Для AI «конкретность — это продуктивность»: абстрактную идею нужно превратить в детальный документ требований (PRD), который затем переиспользуется.
- Ключи моделей хранятся в переменных окружения, чтобы не попадать в код.

## Инструменты и технологии
- Claude Code, Codex, OpenCode, Claude Code Router
- Модели: GLM-4.6, Kimi K2, MiniMax, DeepSeek, Doubao, Qwen, GPT-5
- npm, переменные окружения, MCP, CLAUDE.md / AGENTS.md, Oh-My-OpenAgent

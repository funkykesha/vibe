## О чём урок
Agent Teams — функция Claude Code, позволяющая нескольким независимым экземплярам AI работать как настоящая команда разработки: одни делают фронтенд, другие бэкенд, третьи тесты, при этом они работают параллельно, общаются и координируются. Урок объясняет архитектуру, отличие от Subagent и показывает разработку RPG-игры командой агентов.

## Ключевые темы
- Ограничения одиночного AI: последовательная обработка, перегрузка контекста, единственная точка зрения, потолок эффективности.
- Agent Teams vs Subagent: звёздная топология (все докладывают главному) против сетевой (участники общаются напрямую); Subagent — раздача задач, Agent Teams — настоящая команда.
- Архитектура: Team Lead (координатор), Teammates (независимые экземпляры с собственным контекстом 200K), TaskList (общая доска задач с зависимостями и файловыми блокировками), Messaging System (обмен сообщениями через файловую систему).
- Запуск: включение экспериментальной функции в `settings.json` (`agentTeams: true`), опциональный режим split-panes через tmux.
- Практика: разработка RPG-игры в стиле Pokémon силами пяти участников (архитектура, боевая система, диалоги, рендеринг карты, UI/звук).

## Главные выводы
- Каждый участник имеет полностью изолированный контекст 200K токенов, что устраняет проблему «забывания» в длинных диалогах.
- По внутренним тестам Anthropic параллельная работа команды ускоряет крупный рефакторинг примерно на 50%.
- Subagent дешевле и проще для быстрых независимых задач; Agent Teams нужны для сложных систем с частой координацией между модулями.
- Состояние команды полностью прозрачно — оно хранится в виде файлов в `~/.claude/teams/` и `~/.claude/tasks/`.

## Инструменты и технологии
- Claude Code Agent Teams (экспериментальная функция), settings.json
- tmux (режим split-panes), файловая система для обмена сообщениями
- Пример стека: React + TypeScript + Vite, Tailwind CSS, Framer Motion, Zustand, Web Audio API

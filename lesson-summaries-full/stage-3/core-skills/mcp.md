## О чём урок
MCP (Model Context Protocol) — протокол, позволяющий Claude Code подключаться к внешним инструментам и сервисам. С ним Claude Code превращается из помощника, который умеет лишь читать и писать локальные файлы, в «суперпомощника» с доступом к GitHub, базам данных, API, облачным сервисам и автоматизации браузера. Урок объясняет настройку, способы транспорта и лучшие практики.

## Ключевые темы
- Что даёт MCP: работа с GitHub Issues/PR, запросы к SQLite/PostgreSQL, доступ к Notion/Slack, погода, карты, автоматизация браузера.
- Конфигурация: пользовательский уровень (`~/.claude.json`) и проектный (`.claude/mcp.json`); приоритет проектного уровня для командной работы.
- Управление на естественном языке: добавление, проверка, удаление и обновление серверов через обычные запросы; диагностика `/doctor`.
- Три типа транспорта: STDIO (локальный процесс), HTTP (удалённый сервис), SSE (server-sent events).
- Лучшие практики: проектная конфигурация, вынос секретов в переменные окружения, фиксация версий (`@version`), документирование (`.claude/README.md`).

## Главные выводы
- Проектная конфигурация предпочтительнее: её можно коммитить в Git, и вся команда получает одинаковый набор MCP-серверов.
- Никогда не хардкодьте ключи в конфиге — используйте переменные окружения, чтобы избежать утечки при коммите.
- Фиксируйте версии серверов, иначе `npx -y` всегда тянет последнюю и может сломать совместимость.
- Skills и MCP дополняют друг друга: Skills говорят «как делать», MCP даёт «чем делать».

## Инструменты и технологии
- MCP (Model Context Protocol), Claude Code
- Серверы: server-github, server-sqlite, server-postgres, server-filesystem, server-puppeteer, server-brave-search
- npx, JSON-конфигурация, /doctor, реестры (MCP.so, Smithery, Official MCP Registry)

## О чём урок
Skills — это способ упаковать экспертные знания, рабочие процессы и лучшие практики в переиспользуемые «пакеты навыков». Вместо того чтобы каждый раз объяснять Claude требования, вы один раз определяете навык, и он выполняет работу по заданному стандарту. Урок проводит от установки первых навыков до глубокого понимания внутреннего устройства.

## Ключевые темы
- Зачем нужны Skills: устраняют повторяющиеся инструкции, накапливают командные знания, унифицируют стандарт, экономят токены.
- Быстрый старт: установка `find-skills` (поиск навыков на естественном языке) и практические навыки — remotion-dev/skills (видео), frontend-design (дизайн), frontend-slides (HTML-презентации).
- Структура SKILL.md: YAML frontmatter (name, description, allowed-tools) + Markdown-инструкции; глобальные (`~/.claude/skills/`) и проектные (`.claude/skills/`) навыки.
- Skills vs MCP: Skills — знания и процессы («как делать»), MCP — инструменты и интерфейсы («чем делать»); они дополняют друг друга.
- Создание навыков: через диалог с Claude или с помощью `skill-creator`; интеграция с Hooks и Commands; командная работа через Git.
- Внутреннее устройство: трёхуровневая прогрессивная загрузка (метаданные → инструкции → ресурсы), маршрутизация через чистый LLM-вывод без хардкода, принцип «использовал и забыл».

## Главные выводы
- Skills — это не исполняемый код, а высокоуровневые промпты, динамически внедряемые в контекст по мере необходимости.
- Трёхуровневая загрузка резко экономит токены: при запуске грузятся только метаданные (~30-50 токенов на навык), полное содержимое — лишь при срабатывании.
- Качество `description` критично: чем конкретнее описание и сценарии срабатывания, тем точнее Claude подбирает навык.
- Правило: если вы дважды повторяете одну и ту же инструкцию — пора создать Skill.

## Инструменты и технологии
- Claude Code Skills, SKILL.md (YAML frontmatter + Markdown)
- find-skills, skill-creator, skills.sh, npx skills
- Hooks, Commands, Agent Skills (открытый стандарт agentskills.io)

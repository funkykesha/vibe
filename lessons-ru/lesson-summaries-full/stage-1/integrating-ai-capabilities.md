## О чём урок
Урок превращает статичный прототип в живое приложение, которое реально вызывает AI-сервисы. Читатель разбирается с базовыми понятиями API, учится получать API Key и читать официальные документации, а затем на практике подключает текстовую модель DeepSeek и несколько сервисов генерации/понимания изображений, доверяя интеграцию AI IDE.

## Ключевые темы
- Базовые понятия API: API Key, Endpoint, базовый URL, запрос, ответ, обработка ошибок
- Безопасность API Key: не публиковать, не зашивать в код и не коммитить в Git; в учебных целях допустимо вставлять в AI IDE напрямую
- Подключение текстовой генерации DeepSeek за 3 шага: создать ключ, найти пример в документации, вставить ключ и пример в AI IDE
- Проверка, что вызов реальный (а не зашитый ответ): кастомный ввод и страница использования платформы
- Выбор других текстовых моделей: MiniMax через OpenAI-совместимый интерфейс (меняются только URL, ключ и имя модели)
- Подключение «изображение → текст» (VLM): Qwen3 VL через SiliconFlow для генерации описаний и ключевых слов товара
- Подключение генерации изображений: Seedream (即梦) от ByteDance для постеров и главных изображений товаров
- Другие сервисы изображений: Recraft (дизайн/иллюстрации), Qwen Image / Qwen Image Edit через SiliconFlow
- Как находить «более сильную» модель: арены LMArena и Artificial Analysis

## Главные выводы
- Суть API проста: отправить запрос в нужном формате и получить результат в том же формате
- Процесс интеграции любой модели одинаков: пользователь нажимает кнопку, фронтенд формирует запрос, результат показывается на странице
- Поскольку большинство моделей дают OpenAI-совместимый интерфейс, переключение между ними сводится к смене ключа, базового URL и имени модели
- При чтении документации достаточно следить за тремя вещами: endpoint, API key и параметры вызова
- При сбоях генерации изображений важно показывать полную причину ошибки (несоответствие, ошибка запроса, таймаут), а не просто «не удалось»; при необходимости отключать водяной знак и потоковый ответ

## Инструменты и технологии
- API, API Key, Endpoint, SDK, OpenAI-совместимый интерфейс, curl, Python
- DeepSeek, MiniMax (M3, M2.7), Qwen3 VL, Seedream 4.5, Recraft, Qwen Image / Qwen Image Edit
- SiliconFlow, Volcengine (Ark), base64, VLM, LLM
- LMArena, Artificial Analysis

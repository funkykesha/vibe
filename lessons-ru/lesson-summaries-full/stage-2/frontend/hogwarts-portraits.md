## О чём урок
Проектный урок, в котором вы создаёте «живой магический портрет» в духе Гарри Поттера — персонажа (звезда, историческая личность или аниме-герой), с которым можно общаться и который меняет выражение лица в зависимости от настроения. Урок связывает воедино проектирование интерфейса, генерацию кода, подключение Dify-воркфлоу и публикацию в интернете.

## Ключевые темы
- Идея проекта Hogwarts Portraits: трёхколоночный интерфейс (чат слева, портрет по центру, лента соцсети справа)
- Сбор материалов о персонаже: публичные высказывания как few-shot примеры для имитации стиля речи, тексты для базы знаний Dify
- Прототипирование страницы (от наброска в PowerPoint до Figma/MasterGo) и связь стиля с личностью персонажа
- Генерация интерфейса через Figma Make, MasterGo AI или мультимодальный AI и запуск кода локально
- Система эмоций: модель выдаёт «значение настроения», по которому фронтенд отображает разные изображения портрета (грусть, гнев, спокойствие, радость)
- Воркфлоу Dify: узлы RESPONSE, эмоциональной оценки, if/else для публикации в соцсеть, узел RESULT; подключение Chat API
- Публикация: загрузка на GitHub и деплой через Zeabur; хранение ключей в переменных окружения

## Главные выводы
- Чтобы портрет ощущался как реальный человек, нужны и знания (база знаний Dify), и стиль речи (промпт-инжиниринг системного промпта)
- Эмоции делают портрет «живым»: числовое значение настроения управляет сменой изображения
- Секреты (Dify API key) обязательно хранятся в переменных окружения, а не в коде; их можно задавать при деплое или через скрытую настройку на странице
- Стоит экспериментировать с разными визуальными стилями (винтаж, мультяшный, китайский поэтический стиль), не меняя само изображение портрета
- Можно начинать не с нуля, а модифицируя официальный референс-проект

## Инструменты и технологии
- Figma / MasterGo, Figma Make, мультимодальный AI (Gemini, Qwen)
- Lovart (генерация набора изображений эмоций персонажа)
- Dify (база знаний, RAG, воркфлоу, Chat API), Trae (AI IDE)
- GitHub (SSH, репозиторий, push), Zeabur (деплой в публичный доступ)
- PowerPoint (черновой прототип), HTML / React

# Курс Easy-Vibe на русском языке

Русскоязычные материалы по курсу [Datawhale · easy-vibe](https://github.com/datawhalechina/easy-vibe) (этапы 1–3) — от первых шагов в AI-программировании до RAG, MCP и кроссплатформенной разработки.

Один и тот же набор из **47 уроков** собран здесь в трёх вариантах — выберите глубину под свою задачу.

## 📚 Три коллекции

| Коллекция | Что это | Когда читать |
|-----------|---------|--------------|
| 🟢 [**Кратко**](lesson-summaries/README.md) | Конспект: суть, ключевые темы, выводы и инструменты | Быстро понять, о чём урок, и решить, нужен ли он |
| 🟡 [**Расширенно**](lesson-summaries-full/README.md) | Подробное изложение с пояснениями и контекстом | Разобраться в теме без чтения оригинала целиком |
| 🔵 [**Полный перевод**](lesson-originals-ru/README.md) | Полный перевод оригинальных уроков с китайского | Изучать тему максимально подробно |

Все три коллекции имеют одинаковую структуру файлов, а каждый урок снабжён навигационным блоком со ссылками на остальные версии и на оригинал 中文.

> Источник: каталог `docs/zh-cn/` репозитория easy-vibe (оригинал на китайском). Справочная база (`appendix`) и проектные задания (PRD) не входят.

## 🗂 Структура

```
lessons-ru/
├── lesson-summaries/        🟢 Кратко
├── lesson-summaries-full/   🟡 Расширенно
├── lesson-originals-ru/     🔵 Полный перевод
└── link_lesson_versions.py  служебный скрипт перекрёстных ссылок
```

Внутри каждой коллекции уроки разложены по этапам:

- **Этап 1 · Базовый уровень** — карта курса, AI IDE, поиск идеи, сборка прототипа (7 уроков)
- **Этап 2 · Фронтенд / Бэкенд / AI-способности** — Figma, дизайн в код, библиотеки компонентов, Git, Supabase, Stripe, Dify и др. (15 уроков)
- **Этап 3 · Ключевые навыки / Кроссплатформа / Продвинутый AI / Личный бренд** — Claude Code, MCP, Skills, Agent Teams, мобильная и десктоп-разработка, RAG, LangGraph, LlamaIndex (25 уроков)

Полные оглавления — в README каждой коллекции.

## 🔧 Сопровождение

Навигационные блоки между версиями («Кратко · Расширенно · Полный перевод») и шапки коллекций генерируются автоматически:

```bash
python3 lessons-ru/link_lesson_versions.py
```

Скрипт идемпотентен — он находит существующий блок по маркеру `<!-- nav -->` и заменяет его, поэтому запускать его можно сколько угодно раз. Запускайте после добавления новых уроков или изменения списка коллекций.

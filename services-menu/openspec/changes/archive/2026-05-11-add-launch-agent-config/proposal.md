## Зачем

Меню сейчас отслеживает и перезапускает жестко заданные LaunchAgent label, но для добавления нового сервиса все еще нужно вручную писать plist вне приложения. Это изменение позволит создавать LaunchAgent прямо из меню, сохраняя текущие соглашения по label, имени plist и путям логов.

## Что меняется

- Добавляется пункт меню для создания нового LaunchAgent-конфига.
- Добавляется одно окно редактора с четырьмя полями: `name`, `command`, `path-to-start` и опциональный `WorkingDirectory`.
- В окне редактора есть кнопки "Отмена" и "Применить"; "Применить" запускает валидацию и создание plist.
- Генерируется LaunchAgent plist в `/Users/agaibadulin/Library/LaunchAgents/`.
- Label, имя plist-файла и директория логов выводятся из введенного имени.
- После применения конфига показывается успех или ошибка валидации/записи.

## Возможности

### Новые возможности

- `launch-agent-config-creation`: создание LaunchAgent plist-файлов из данных, введенных через меню.

### Измененные возможности

Нет.

## Влияние

- Затрагивает построение меню и rumps-callbacks в `app.py`.
- Добавляет AppKit-форму поверх rumps-приложения для ввода нескольких полей в одном окне.
- Добавляет запись файлов в `/Users/agaibadulin/Library/LaunchAgents/` и создание директории логов в `/Users/agaibadulin/Library/Logs/<name>/`.
- Использует штатную генерацию plist, чтобы не собирать XML вручную и не получать некорректный plist.

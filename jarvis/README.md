# Jarvis

Голосовой диспетчер-«Джарвис» поверх всех окон на Mac, который оркеструет
Codex-агентов. Микро-кнопка-overlay: клик — звонок, повторный клик или команда
«положи трубку» — завершение. Что-то ассистент решает сам, что-то делегирует
Codex (новый интерактивный таб iTerm, запуск асинхронный — болтовня не ждёт
завершения задачи).

> **Статус: итерация 1** — базовый прототип. Полный роадмап из 7 итераций см. в
> [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Что уже работает (итерация 1)

- Плавающая микро-кнопка поверх всех окон, включая полноэкранные Spaces;
  перетаскивается мышью.
- Клик → «звонок»: появляется поле ввода, кнопка подсвечивается.
- Голос → текст через **[Handy](https://github.com/cjpais/Handy)** (локальный
  push-to-talk STT, ставится отдельно): надиктованный текст попадает в поле,
  Enter — отправка.
- Роутер решает: ответить (заглушка в итерации 1) или **делегировать** —
  открыть интерактивный Codex в новом табе iTerm в папке `base_dir`. Запуск
  асинхронный.
- «Положи трубку» голосом или повторный клик завершают звонок.

## Требования

- macOS (overlay использует AppKit через PyObjC).
- [iTerm2](https://iterm2.com/) — Codex запускается в его табе через AppleScript.
- [Codex CLI](https://github.com/openai/codex) в `PATH`.
- [Handy](https://github.com/cjpais/Handy) для голосового ввода (опционально —
  можно печатать в поле руками).

## Запуск (debug)

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python jarvis.py
```

Конфиг создаётся при первом запуске в `~/.config/jarvis/config.json`:

| Поле | Назначение | Дефолт |
|------|------------|--------|
| `base_dir` | папка, где запускается Codex («base prog») | `~/prog` |
| `codex_cmd` | команда старта интерактивного Codex | `codex` |
| `voice_provider` | `handy` или `stub` | `handy` |

## Тесты

Чистое ядро (роутер, сборка AppleScript, конфиг, voice-провайдеры) тестируется
без AppKit и микрофона:

```bash
python -m pytest tests/ -q
```

UI-слой (`overlay.py`, `jarvis.py run()`) проверяется только на самом Mac —
в CI/Linux он не импортируется.

## Структура

| Файл | Роль |
|------|------|
| `jarvis.py` | точка входа: NSApplication + проводка overlay → router → Codex |
| `overlay.py` | плавающая микро-кнопка + поле ввода (PyObjC NSPanel) |
| `router.py` | классификация реплики: ответить / делегировать / положить трубку |
| `codex_launcher.py` | запуск интерактивного Codex в новом табе iTerm (async) |
| `voice.py` | абстракция `VoiceProvider` (Handy / stub) |
| `config.py` | загрузка/сохранение конфига |

# Как разработать PWA локальное приложение — превратите веб-страницу в настоящее приложение

# 1 Что такое PWA и разработка PWA

В этом учебнике мы пройдём полный цикл: **от обычного веб-проекта к приложению, которое можно установить на рабочий стол компьютера и главный экран телефона, и которое будет работать даже без интернета.** Вы собственноручно преобразуете приложение React в PWA, разверните его в интернете и установите на телефон.

Мы разработаем приложение **Помидорная ферма (Tomato Farm)** — приложение PWA, которое идеально объединяет технику помидорного таймера с игрой в выращивание овощей. Получайте очки за 25 минут концентрации, используйте очки для покупки семян и посадки культур, а с повышением уровня откройте больше грядок и премиум-семена. Самое главное — приложение работает и без интернета, а все данные сохраняются локально.

Для этого учебника вам понадобится минимум:

- Компьютер (Windows или Mac)
- Node.js (версия 18.0 и выше)
- Ваш AI помощник по программированию (Cursor / Trae / Claude Code и т.д.)
- Мобильный телефон (для опробования установки мобильной версии)

## 1.1 Определение PWA

**PWA (Progressive Web App)** — это специальная веб-страница, которая получает способность "кешировать и управлять собой" благодаря технологии **Service Worker**.

### Почему обычные веб-сайты не могут работать офлайн, а PWA может?

Обычный веб-сайт при каждом открытии должен загружать HTML, CSS, JS файлы с сервера, а при отсутствии интернета полностью перестаёт работать. PWA при первом посещении использует **Service Worker** (JS скрипт, работающий в фоне браузера) для кеширования этих файлов на локальный диск. После этого, даже если интернет выключен, Service Worker будет читать файлы прямо из кеша, позволяя странице нормально отображаться.

**Аналогия**: обычный веб-сайт похож на то, как каждый раз ходить в библиотеку брать книги (нужен интернет), а PWA похож на то, как купить книги и положить их на полку дома (после первой загрузки, можно читать офлайн).

### PWA vs обычный веб-сайт vs нативное приложение

| Особенность | Обычный веб-сайт | PWA | Нативное приложение |
|------|---------|-----|---------|
| **Установка** | Не требуется | Опциональна (добавить на рабочий стол) | Необходимо скачать из магазина приложений |
| **Офлайн использование** | ❌ Невозможно | ✅ Возможно (после кеширования) | ✅ Возможно |
| **Способ обновления** | Автоматическое обновление при обновлении | Автоматическое/фоновое обновление | Пользователь обновляет вручную |
| **Размер** | Нет | Несколько сотен КБ ~ несколько МБ | Десятки МБ и более |
| **Стоимость разработки** | Низкая | Низкая (один код для всех платформ) | Высокая (iOS/Android разработка отдельно) |

**Одна фраза резюме**: PWA — это "веб-страница, которая сама себя сохраняет" — она имеет лёгкость веб-сайта (без установки, автоматическое обновление) и опыт нативного приложения (офлайн доступ, добавление на рабочий стол).

![Сравнение PWA и других подходов](https://raw.githubusercontent.com/datawhalechina/easy-vibe/main/docs/zh-cn/stage-3/cross-platform/pwa-local-app/images/image0.png)

## 1.2 Почему выбрать PWA?

В эпоху Vibe Coding PWA — одно из лучших соотношений цены и качества решений для "кроссплатформной разработки":

| Критерий | Нативное приложение | PWA |
|---------|---------|-----|
| Стоимость разработки | Нужна отдельная разработка iOS / Android / Desktop | Один код, работает везде |
| Способ установки | Нужно скачивать из магазина приложений | Установка прямо из браузера, моментально |
| Обновление | Пользователь должен обновлять вручную | Автоматическое обновление, прозрачное для пользователя |
| Размер приложения | Десятки МБ | Обычно только несколько сотен КБ |
| Офлайн способность | По умолчанию поддерживается | Поддерживается через Service Worker |
| Применение | Нужен глубокий доступ к железу (AR/Bluetooth и т.д.) | Показ контента, утилиты, облегчённые приложения |

**Вывод одной фразой**: если ваше приложение не требует функций AR с доступом к камере или Bluetooth, PWA — почти оптимальный выбор.

## 1.5 Дорожная карта этого учебника

Чтобы сделать процесс обучения интересным, весь этот учебник будет строиться вокруг занимательного и практичного примера — **"Помидорная ферма"**. Это игра с помидорным таймером и выращиванием овощей, идеально объединяющая работу с концентрацией и игровые стимулы. Мы объединим режим Vibe Coding с AI помощником и разберём процесс от нуля до установки на телефон на повторно используемую дорожную карту:

1. **Создание осведомлённости и среды**: разберитесь в форме PWA, установите Node.js и AI помощник, убедитесь в отлаженном инструментарии.
2. **Построение скелета проекта**: создайте React + TypeScript проект, который успешно работает локально.
3. **AI итеративная разработка**: через диалог с AI, начиная с помидорного таймера обратного отсчёта, постепенно реализуйте систему выращивания, систему уровней, отображение культур в SVG и другие функции.
4. **Конфигурация PWA и тестирование офлайна**: добавьте Service Worker и Manifest, протестируйте офлайн способность.
5. **Развёртывание и установка на телефон**: разверните на Vercel и получите HTTPS адрес, установите и используйте на телефоне.

Этот раздел только рисует полную картину, не вдаваясь в конкретные команды. На данный момент нужно помнить только эту главную линию: **подготовка среды → построение скелета → описание и генерация AI → конфигурация PWA → развёртывание** . В следующих разделах мы пройдём каждый шаг вместе.

# 2 Подготовка среды разработки

## 2.1 Инструменты, которые будут использоваться в этом учебнике

Во всём процессе разработки нам нужно использовать три инструмента, которые выполняют роли "проектирования", "строительства" и "приёмки".

- **AI помощник по программированию (Cursor / Trae / Claude Code)**: это ваш **AI партнёр по программированию**. В режиме Vibe Coding нам больше не нужно вводить код строка за строкой, вместо этого мы в основном говорим AI на естественном языке, что мы хотим, в диалоге AI помощника, и оно генерирует и модифицирует код.
- **Node.js + Vite**: это **фабрика по производству проектов**. Node.js предоставляет среду выполнения JavaScript, Vite — инструмент нового поколения для сборки фронтенда, с очень высокой скоростью, особенно подходит для разработки PWA приложений.
- **Мобильный телефон**: как **терминал для тестирования** смотреть результаты работы, можно напрямую в мобильном браузере получить доступ к развёрнутому PWA и протестировать реальную установку и офлайн функции.

## 2.2 Установка Node.js

Node.js — это основная среда для разработки PWA. Пожалуйста, посетите официальный сайт [https://nodejs.org](https://nodejs.org), загрузите **LTS (долгосрочную поддержку) версию** (этот учебник основан на Node.js 18.x и выше).

После загрузки, как при установке обычного софта, двойным щелчком запустите файл, сохраняйте параметры по умолчанию и все "Далее" до завершения установки.

После установки откройте терминал (пользователи Windows откройте CMD или PowerShell, пользователи Mac откройте Terminal), введите следующую команду для проверки успешной установки:

```bash
node --version
npm --version
```

Если вы видите вывод версии (например `v18.17.0` и `9.6.7`), установка успешна.

![Проверка установки Node.js](https://raw.githubusercontent.com/datawhalechina/easy-vibe/main/docs/zh-cn/stage-3/cross-platform/pwa-local-app/images/image1.png)

## 2.3 Установка AI помощника по программированию

AI помощник по программированию — это главное "поле боя" для **Vibe Coding**. Вы можете думать о нём как о "редакторе кода с встроенным супер AI".

**Рекомендуемые варианты:**

- **Trae**: посетите официальный сайт [https://www.trae.cn](https://www.trae.cn), загрузите версию в соответствии с вашей операционной системой
- **Cursor**: посетите официальный сайт [https://cursor.sh](https://cursor.sh), загрузите и установите
- **Claude Code**: если вы уже используете Claude, вы можете напрямую использовать функцию Claude Code

Процесс установки очень простой, как при установке обычного софта — двойной щелчок по инсталлятору и следуйте приглашениям "Далее" для завершения. Как только вы подготовите этот инструмент, в последующей практике нам больше не нужно смотреть на скучный код, мы можем открыть проект здесь и через диалоговое окно использовать естественный язык для управления AI помощью нам писать код и исправлять ошибки.

## 2.4 Создание нового проекта

Откройте ваш AI помощник по программированию, в диалоговом окне введите следующий Prompt:

```
Пожалуйста помогите мне создать React проект, имя проекта tomato-farm-pwa, используется для приложения Помидорная ферма.
Нужна поддержка TypeScript, и добавить PWA функции (это то, что позволяет веб-странице быть установленной на рабочий стол телефона).
```

AI автоматически выполнит следующие шаги:

**Шаг один: Создание проекта**

```bash
npm create vite@latest tomato-farm-pwa -- --template react-ts
```

**Шаг второй: Входу в проект и установка зависимостей**

```bash
cd tomato-farm-pwa
npm install
```

**Шаг третий: Установка PWA плагина**

```bash
npm install vite-plugin-pwa -D
```

После завершения работы AI, структура вашего каталога проекта будет примерно такой:

```
tomato-farm-pwa/
├── public/              # Статические ресурсы (значки, SVG материалы положить сюда)
├── src/
│   ├── App.tsx          # Главный компонент
│   ├── main.tsx         # Файл входа
│   └── App.css          # Стили
├── index.html           # HTML входная точка
├── vite.config.ts       # Конфигурация Vite (конфигурация PWA пишется здесь)
├── package.json
└── tsconfig.json
```

## 2.5 Понимание структуры проекта

После успешного создания проекта, нам нужно понять функцию нескольких ключевых файлов:

| Файл/каталог | Описание функции |
|----------|---------|
| `src/App.tsx` | Главный компонент приложения, вся логика страницы пишется здесь |
| `src/main.tsx` | Входной файл приложения, отвечает за монтирование приложения React |
| `vite.config.ts` | Файл конфигурации Vite, конфигурация ядра PWA пишется здесь |
| `public/` | Каталог статических ресурсов, значки PWA и материалы SVG положить сюда |
| `index.html` | Файл входа HTML, обычно не требует модификации |

Как новичок, нам просто нужно сконцентрироваться на трёх файлах:

- `App.tsx`: контролирует поведение программы, решает "что показывать на экране"
- `vite.config.ts`: конфигурирует функцию PWA, решает "как приложение устанавливается и кешируется"
- `public/`: хранит значки приложения и материалы

## 2.7 Конфигурирование vite-plugin-pwa

Это самый критичный шаг. Откройте `vite.config.ts`, попросите AI помочь вам конфигурировать PWA плагин:

```
Пожалуйста помогите мне изменить vite.config.ts на PWA конфигурацию, позволяя веб-странице быть установленной на рабочий стол телефона:
- Имя приложения "Помидорная ферма", тема зелёная
- Используйте icon-192.png и icon-512.png из каталога public как значки
- Включить автоматическое обновление
- Кешировать все js, css, html и файлы картинок, позволяя приложению работать офлайн
```

AI поможет вам сгенерировать конфигурацию похожую на эту:

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { VitePWA } from 'vite-plugin-pwa'

export default defineConfig({
  plugins: [
    react(),
    VitePWA({
      registerType: 'autoUpdate',
      manifest: {
        name: '番茄农场',
        short_name: '番茄农场',
        description: '专注种菜，收获成长',
        theme_color: '#4CAF50',
        background_color: '#ffffff',
        display: 'standalone',
        icons: [
          {
            src: '/icon-192.png',
            sizes: '192x192',
            type: 'image/png'
          },
          {
            src: '/icon-512.png',
            sizes: '512x512',
            type: 'image/png'
          }
        ]
      },
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg}']
      }
    })
  ]
})
```

**Интерпретация ключевой конфигурации:**

* `registerType: 'autoUpdate'`: когда вы опубликуете новую версию, пользователь при следующем открытии приложения автоматически обновится, без ручных операций.
* `display: 'standalone'`: после установки работает в независимом окне, без адресной строки браузера, выглядит как нативное приложение.
* `workbox.globPatterns`: скажите Service Worker какие типы файлов кешировать, эти файлы можно получить доступ и офлайн.

# 3 Разработка Помидорной фермы PWA

В первых двух разделах мы уже разобралась в том, что такое PWA, и подготовили среду разработки. С этого раздела мы более не будем разговаривать в теории, мы входим в практику. Мы будем использовать режим Vibe Coding, с нуля создавая занимательное и практичное приложение — **"Помидорная ферма" (Tomato Farm)** . Оно не только идеально объединяет технику помидорного таймера с игровыми стимулами, но и охватывает ключевые элементы разработки PWA: **взаимодействие UI (помидорный таймер), сохранение данных (очки и культуры), офлайн способность (кеширование Service Worker)**.

Далее, пожалуйста, следуйте моему ритму и отправьте AI первую инструкцию.

## 3.1 Первая "общая инструкция": от нуля к единице

В режиме Vibe Coding нам не нужно, как при традиционной разработке, сначала создавать файл макета, потом писать логику кода. Нам нужно сделать **описать все требования в один раз, позволяя AI помочь нам сгенерировать первую версию наброска, которая может работать**.

Откройте папку проекта, который мы только что создали, в AI помощнике по программированию, в диалоговом окне введите следующий Prompt:

```
Пожалуйста помогите мне написать главную страницу приложения Помидорная ферма, включая следующие функции:

**Функция помидорного таймера:**
- Таймер обратного отсчёта на 25 минут, можно начать, остановить, перезагрузить
- Показывать оставшееся время и прогресс бар
- После завершения концентрации, дайте пользователю 10 очков

**Функция выращивания овощей:**
- 3 грядки, в начале только первая может использоваться, потом нужно повысить уровень чтобы открыть
- В магазине можно купить семена: морковь 5 очков, помидор 10 очков, кукуруза 15 очков
- После покупки семян, посадив на земле, культура медленно растёт, после созревания можно сбирать и обменивать на очки

**Система уровней:**
- На основании общих очков повышение уровня: 0-100 очков это начинающий фермер, 100-300 очков это опытный фермер, 300 очков и выше это мастер фермы
- После повышения уровня разблокируйте новые грядки и более высокий уровень семян

**Дизайн интерфейса:**
- Вверху показывайте уровень, очки и прогресс бар повышения
- В середине помидорный таймер обратного отсчёта
- Снизу сетка грядок
- В низу кнопка магазина
- В целом используйте зелёную тему, выглядит свежо и мило
- Должна поддерживать мобильный экран

**Сохранение данных:**
- Все данные (очки, уровень, состояние грядок) должны быть сохранены, обновление страницы не будет потеряно
```

После отправки инструкции, вы увидите, что AI начинает думать и анализировать структуру вашего проекта. Через несколько секунд, это прямо сгенерирует полный код `App.tsx`.

1. Через его ответ, мы можем видеть его логику мышления, логику взаимодействия и т.д.
2. Мы можем напрямую видеть какой код он модифицировал
3. Если нам не нравится генерированный результат, мы можем вернуться на предыдущую версию

## 3.3 Оптимизация и итерация (добавление SVG культур и анимации)

На данный момент, наше приложение уже имеет набросок: помидорный таймер обратного отсчёта, система посадки, система уровней. Но оно может быть ещё грубо, культура может быть просто простой текст или квадрат. Далее, мы через добавление красивых SVG культур и анимации роста, позволим этой помидорной ферме стать живой и интересной.

**Это самое заманчивое место режима Vibe Coding.** При традиционной разработке, рисование SVG графики и реализация сложной анимации роста обычно — кошмар новичков. Вам не только нужно справиться с рисованием путей SVG, но и вычислить кривую времени анимации. Но в режиме Vibe Coding, эти низкоуровневые технические детали вам полностью не нужно заботиться, вам просто нужно, как режиссёр, сказать AI: "добавьте культурам красивые SVG картины, посадка должна иметь анимацию роста", сложная реализация кода моментально завершится.

**Шаг один: Подготовьте SVG материалы культур**

Вы можете позволить AI прямо рисовать SVG в коде, или подготовить готовые SVG файлы положить в каталог `public/`. Этот учебник рекомендует позволить AI прямо генерировать код SVG, это больше гибкий.

**Шаг два: Отправьте инструкцию по итерации**

Вернитесь к AI помощнику по программированию, введите следующий Prompt:

```
Пожалуйста помогите мне сделать культуры выглядели красивее, добавьте анимацию роста:

**Картина культур:**
- Морковь: оранжевое тело, зелёные листья
- Помидор: красный круг, с зелёными маленькими листьями
- Кукуруза: жёлтый кочан, зелёная оболочка
Все просто рисуйте простыми формами

**Анимация роста:**
- Только что посажено это маленький росток, медленно растёт, в конце созревает
- Разделено на 3 стадии показывая разные образы

**Эффект сбора:**
- Щелкните созревшую культуру, проигрывайте простую анимацию сбора
- Показывайте сколько очков получили

**Оптимизация в целом:**
- Грядка квадрат должна иметь рамку и цвет фона
- Культура показывается в середине квадрата
- Выглядело милее
```

AI снова модифицирует код, помогая вам справиться со сложным рисованием SVG и логикой анимации. После модификации, обновите страницу браузера, вы должны увидеть красивые картины культур и гладкие анимации роста.

# 4 Локальный опыт PWA

## 4.1 Построение и предпросмотр

Service Worker PWA только работает в производственной сборке (в режиме разработки не будет регистрироваться). Поэтому нам нужно сначала построить, потом предпросмотреть:

```
Пожалуйста помогите мне выполнить следующие команды:
1. npm run build (построить производственную версию)
2. npm run preview (запустить локальный сервер предпросмотра)
```

После построения, Vite создаст все файлы в каталоге `dist/`, включая автоматически генерированный `sw.js` (Service Worker) и `manifest.webmanifest`.

После запуска сервера предпросмотра, откройте браузер и посетите адрес, который он предложит (обычно это `http://localhost:4173`).

## 4.2 Установка PWA на компьютер

После открытия адреса предпросмотра, вы заметите справа от адресной строки браузера появляется **значок установки** (маленькая стрелка загрузки или знак "+").

**Шаги установки Chrome / Edge:**

1. Щелкните значок установки справа от адресной строки
2. В выскочившем диалоге щелкните **"Установить"**
3. PWA откроется в независимом окне, одновременно создавая ярлык на вашем рабочем столе/меню запуска/Dock

После установки, PWA выглядит как настоящее приложение для рабочего стола — без адресной строки, без вкладок, с собственным окном и значком. Теперь вы можете в любой момент открыть помидорную ферму, начать путь концентрации и выращивания!

![Установка PWA на рабочий стол](https://raw.githubusercontent.com/datawhalechina/easy-vibe/main/docs/zh-cn/stage-3/cross-platform/pwa-local-app/images/image6.png)

**Шаги установки macOS Safari:**

1. Откройте адрес PWA в Safari
2. Щелкните в меню-баре **Файл → Добавить в Dock**
3. Значок PWA появится в Dock

## 4.3 Тестирование офлайн способности

Это самая классная часть PWA. Давайте проверим, действительно ли офлайн может использоваться:

1. Убедитесь, что PWA уже открыт один раз в браузере (позволяя Service Worker кешировать ресурсы)
2. **Отключите интернет** (выключите Wi-Fi или отключите сетевой кабель)
3. Обновите страницу — вы обнаружите **помидорная ферма App по-прежнему нормально загружается!**
4. Начните помидорный таймер — после завершения концентрации получайте очки, покупайте семена и сажайте — все данные нормально сохраняются в localStorage

Вы также можете открыть Chrome DevTools (F12) → Application → Service Workers, и посмотреть состояние работы Service Worker и список кешированных ресурсов.

## 4.4 Сохранение данных и план синхронизации

Теперь ваша помидорная ферма уже может работать офлайн, все данные сохранены в localStorage браузера. Но здесь есть критичный вопрос: **если пользователь изменил устройство, или очистил данные браузера, все данные фермы будут потеряны**. Для серьёзных производственных приложений, нам нужно рассмотреть план сохранения данных и синхронизации между устройствами.

### 4.4.1 Ограничение локального сохранения

Текущее использование localStorage имеет несколько явных ограничений:

| Ограничение | Описание |
|--------|------|
| **Привязка к устройству** | Данные сохраняются только в браузере текущего устройства, смена устройства означает потерю |
| **Ограничение объёма** | Обычно только 5-10МБ места для хранения |
| **Легко потерять** | Пользователь чистит данные браузера, удаляет PWA, всё это приводит к потере данных |
| **Невозможна синхронизация** | Прогресс на телефоне невозможно синхронизировать на компьютер |

Если ваша помидорная ферма только для личного использования маленький инструмент, это может быть не проблемой. Но если вы хотите пользователю долгосрочно вкладывать, накапливать данные, нужен более надёжный план.

### 4.4.2 План первый: облачная синхронизация (рекомендуется)

Самый надёжный план — синхронизировать данные на облачную базу данных. Для PWA, **Supabase** — отличный выбор — предоставляет базу данных PostgreSQL, реальную подписку, аутентификацию пользователя, и имеет свободный план.

**Идея реализации:**

1. **Вход пользователя**: используйте почту/социальные сетевые аккаунты для входа, создайте идентичность пользователя
2. **Автоматическая синхронизация данных**: каждая операция автоматически сохраняется на облаке
3. **Офлайн в первую очередь**: даже при отключении интернета можно продолжить работать, при восстановлении интернета автоматическая синхронизация
4. **Синхронизация между устройствами**: прогресс на телефоне реальном времени синхронизируется на компьютер

**Пример Prompt:**

```
Пожалуйста помогите мне изменить сохранение данных помидорной фермы с localStorage на облачную синхронизацию Supabase:

**Требование функций:**
- Добавить функцию входа пользователя (почта+пароль или Google вход)
- Данные пользователя (очки, уровень, состояние грядок) сохранить в базу данных Supabase
- Офлайн может использоваться обычно, при восстановлении интернета автоматическая синхронизация
- Поддержка синхронизации между устройствами, прогресс на телефоне компьютер тоже может видеть

**Технический стек:**
- Использовать клиент @supabase/supabase-js
- Реализовать оптимистическое обновление (сначала обновить UI, потом синхронизировать на облако)
- Добавить простой индикатор статуса синхронизации
```

**Преимущества:**
- Данные никогда не потеряны, смена устройства только нужно вход чтобы восстановить
- Свободный план достаточен для личного проекта использования
- Поддержать реальную подписку, опыт синхронизации между устройствами хороший

**Недостатки:**
- Требует регистрация и вход пользователя, увеличивает барьер использования
- Требует интернет соединение синхронизации

### 4.4.3 План второй: экспорт/импорт резервной копии

Если вы не хотите внедрить сложный бэкенд сервис, простой план компромисса — **резервная копия вручную с восстановлением**.

**Идея реализации:**

1. **Функция экспорта**: упаковайте данные фермы в JSON файл, позвольте пользователю загружать и сохранять
2. **Функция импорта**: пользователь может выбрать ранее экспортированный JSON файл восстановить данные
3. **Автоматическое напоминание**: периодически напоминайте пользователю резервная копия данные

**Пример Prompt:**

```
Пожалуйста добавьте помидорной ферме функцию резервной копии данные:

**Функция экспорта:**
- На странице параметров добавьте кнопку "Экспортировать данные"
- Упакуйте все данные в localStorage в JSON файл
- Автоматически загрузить на устройство пользователя

**Функция импорта:**
- Добавить кнопку "Импортировать данные", поддержка выбора JSON файла
- После проверки формата файла восстановить данные
- Перед импортом подсказать будет перекрывать текущие данные

**Автоматическое напоминание:**
- Если прошло более 7 дней без резервной копии, показать тёплую подсказку
```

**Преимущества:**
- Реализация простая, не требует бэкенд сервис
- Пользователь полностью контролирует свои данные
- Можно миграция через устройства (передача файла)

**Недостатки:**
- Требует пользователю ручную операцию, опыт не достаточно гладко
- Если забыли резервная копия, данные всё ещё потеряют

### 4.4.4 План третий: синхронизация расширения браузера (пользователи Chrome)

Если ваше PWA в основном направлено на пользователей Chrome, вы можете рассмотреть использование **Chrome Storage Sync API**. Это сервис синхронизации хранилища между устройствами, предоставленный браузером Chrome, данные автоматическая синхронизация на учетную запись Google пользователя.

**Заметьте:** это требует упаковать PWA в форме расширения Chrome, подходит для разработчиков с технической способностью попробовать.

### 4.4.5 Рекомендация выбора плана

| Сценарий | Рекомендуемый план |
|------|----------|
| Инструмент маленький для личного использования | localStorage достаточно, не требует дополнительный план |
| Хочу данные не потеряны, но не хочу слишком сложно | Экспорт/импорт резервной копии |
| Официальный продукт, требует полный пользовательский опыт | Облачная синхронизация Supabase |
| В основном направлено на пользователей Chrome | Chrome Storage Sync |

**Для помидорной фермы как такого приложения, мой рекомендация:**

1. **MVP стадия**: сначала используйте localStorage, быстро проверить идею продукта
2. **Стадия итерации**: добавить функцию экспорт/импорт, дайте пользователю страховку данные
3. **Стадия созревания**: подключить Supabase, реализовать настоящую облачную синхронизацию

Помните: **прогрессирующее расширение** — это ядро концепция PWA. Сначала позволить приложение запуститься, потом постепенно добавить высокоуровневые функции.

4. После подтверждения установки, на рабочем столе телефона появится значок помидорной фермы App

Откройте это, вы обнаружите это в полноэкранном режиме работает, без адресной строки браузера и кнопок навигации, и почти идентично нативному приложению. Теперь вы в любой момент и в любом месте можете начать концентрацию и выращивание!

![Установка PWA на Android](https://raw.githubusercontent.com/datawhalechina/easy-vibe/main/docs/zh-cn/stage-3/cross-platform/pwa-local-app/images/image8.png)

## 6.2 Установка на iPhone

Установка PWA на iOS можно только через браузер **Safari** (другие браузеры не поддерживают):

1. В браузере **Safari** откройте адрес помидорной фермы PWA
2. Щелкните **кнопка разделения** внизу (иконка квадрата со стрелкой вверх)
3. В выскочившем меню выберите **"Добавить на главный экран"**
4. Дайте приложению имя, щелкните **"Добавить"**

Начиная с iOS 26, все веб-сайты добавленные на главный экран автоматически открываются в независимом режиме приложения, это большой улучшение.

> **Известные ограничение iOS**:
> * Пуш уведомление требует iOS 16.4 и выше, и обязательно сначала добавить PWA на главный экран
> * Не поддержать фоновая синхронизация (Background Sync)
> * Пространство хранилища более ограничено чем Android

## 6.3 Используйте Lighthouse проверить ваш PWA

Google предоставил инструмент **Lighthouse**, может дать вашему PWA оценку. Откройте Chrome DevTools (F12) → вкладка Lighthouse → выберите "Progressive Web App" → щелкните "Analyze page load".

Квалифицированная помидорная ферма PWA должна получить полную оценку в PWA оценке. Если есть вычет очков, Lighthouse скажет вам конкретная причина и рекомендация исправления.

# 7 Заключение

Поздравляем! Вы успешно построили помидорный таймер, выращивающий овощи PWA приложение, которое можно установить на компьютер и телефон. Давайте вспомним, что мы сделали:

1. Используйте Vite + React создать помидорную ферму веб приложение
2. Через vite-plugin-pwa добавить Service Worker и Manifest
3. Развернули на Vercel получить HTTPS адрес
4. На компьютере и телефоне успешно установили и протестировали офлайн способность

Теперь ваша помидорная ферма PWA уже может реализовать:
* **Концентрация и выращивание**: через помидорный таймер механизм помочь пользователю концентрироваться на учёбе или работе
* **Игровая мотивация**: через выращивание, повышение уровня, разблокировка нового контента мотивировать постоянное использование
* **Офлайн доступность**: даже без интернета можете продолжить концентрацию, выращивание, управление своей фермой
* **Установка между платформами**: одна разработка, можно устанавливать и использовать на всех видах устройств

Очарование PWA в том, что его "прогрессирующее" — вам не нужно с самого начала делать совершенным. Сначала позволить веб-страницу устанавливаться, офлайн доступ, потом постепенно добавить пуш уведомление, фоновая синхронизация и другие высокоуровневые функции.

**Направления развития:**

* **Пуш уведомление**: использовать Push API + Notification API, при помидорный таймер завершён напомнить пользователю отдыхать, или при культура созревает уведомить сбирать
* **Фоновая синхронизация**: использовать Background Sync API, при интернет восстановления синхронизировать данные фермы пользователя на облако
* **Более умная стратегия кеширования**: использовать разные Workbox стратегии кеширования для разных типов ресурсов (CacheFirst, NetworkFirst, StaleWhileRevalidate)
* **Опубликовать на магазин приложений**: использовать [PWA Builder](https://www.pwabuilder.com/) можно упаковать помидорную ферму PWA в Android APK или Microsoft Store приложение
* **Социальные функции**: добавить система друзей, позволить пользователю взаимно посещать ферму, обмен культур и т.д.

***Один код, все платформы универсальны — это мощь PWA. Концентрация и выращивание, сбор и рост!***

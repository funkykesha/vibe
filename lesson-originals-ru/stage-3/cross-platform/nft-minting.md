# Как быстро разработать и отчеканить NFT — 10 минут для начинающих

# Глава 1: Что такое NFT и смарт-контракты

В этом уроке мы создадим полный цикл: с нуля напишем смарт-контракт NFT, развернём его на тестовой сети Ethereum, отчеканим собственный NFT и посмотрим его на OpenSea. Весь процесс использует инструменты в браузере, не требует установки локального окружения, всё займёт 10 минут.

Для этого урока тебе нужно:

- Браузер Chrome (установи плагин MetaMask кошелька)
- Учётная запись MetaMask кошелька
- Немного Sepolia тестовой ETH (её можно получить бесплатно, далее объясним)

> **Нулевая стоимость, нулевая конфигурация**: используй только инструменты в браузере (Remix IDE), не нужна установка Node.js / Hardhat; код напрямую использует официальный шаблон OpenZeppelin для безопасности; после отчеканки вы видите свой NFT на OpenSea тестовой сети.

## 1.1 Что такое NFT?

NFT (Non-Fungible Token, непомер-обмениваемый токен) — это цифровой актив на блокчейне. Отличие от Bitcoin, Ethereum (которые "помер-обмениваемы"), каждый NFT уникален — как нет двух одинаковых картин в мире.

Ты можешь подумать о NFT как о **"цифровом свидетельстве собственности"**. Может обозначать:

* Владение цифровым рисунком
* Билет на событие
* Игровой инвентарь
* Сертификат об учёбе
* Даже твит в Twitter

**Суть NFT в том, что**: блокчейн технология доказала "этот цифровой объект принадлежит тебе", и это доказательство публично, прозрачно, невозможно подделать.

## 1.2 Что такое смарт-контракт?

Смарт-контракт (Smart Contract) — это программный код, который работает на блокчейне. Ты можешь подумать о нём как **"контракт, который автоматически исполняется"** — после развёртывания на блокчейне он будет автоматически выполняться по коду, никто не может его изменить.

NFT создаются и управляются через смарт-контракты. Когда ты "отчеканиваешь" NFT, на самом деле ты вызываешь функцию в смарт-контракте, которая записывает на блокчейне: "NFT номер #0 принадлежит твоему кошельку".

Мы будем писать контракты на **Solidity** языке. Но не волнуйся, используя готовый шаблон OpenZeppelin, тебе нужно написать всего 15 строк кода.

## 1.3 Какой NFT мы будем отчеканивать?

Мы отчеканим **"Vibe Coder Learning Certificate" NFT** — доказательство что ты завершил этот урок и овладел основам разработки на блокчейне. Этот NFT:

* Будет иметь уникальный номер (Token ID)
* Записан на Ethereum Sepolia тестовой сети
* Видим на OpenSea тестовой сети
* (опционально) Можешь приложить картинку, которую ты выбрал

Конечно, ты можешь изменить на любую тему — AI созданный рисунок, билет на событие, пиксель-арт……完全 во власти фантазии!

## 1.4 Почему использовать тестовую сеть?

Ethereum имеет "основную сеть" и "тестовые сети":

| Сравнение | Основная сеть | Тестовая сеть Sepolia |
|-----------|--------|---------|
| Стоимость ETH | Реальные деньги | Бесплатные, без реальной стоимости |
| Стоимость развёртывания | Платишь реальные деньги (Gas fee) | Полностью бесплатно |
| Сценарий | Официальный выпуск | Обучение, тестирование, разработка |
| Функцио различия | Никаких | Полностью совпадает |

Тестовые сети и основная сеть имеют одинаковые функции, только отличие что на тестовой ETH не имеет реальной стоимости. Поэтому мы можем спокойно учиться и экспериментировать на тестовой сети, не боясь потратить деньги.

## 1.5 Дорожная карта этого урока

Мы выполним следующие шаги:

1. **Подготовить кошелёк и тестовые токены** (2 минуты): установить MetaMask, получить бесплатные тестовые ETH
2. **Написать и развернуть смарт-контракт NFT** (4 минуты): в Remix IDE написать контракт NFT и развернуть на Sepolia
3. **Отчеканить NFT и посмотреть результат** (4 минуты): вызвать контракт для отчеканивания NFT, проверить на Etherscan и OpenSea
4. **Продвинуто: добавить картинку к NFT** (опционально): использовать IPFS для хранения картинок, сделать NFT полноценным

# Глава 2: Подготовить кошелёк и тестовые токены (2 минуты)

## 2.1 Установить MetaMask кошелёк

MetaMask — самый популярный Ethereum кошелёк, это браузер-расширение, которое позволяет взаимодействовать с приложениями на блокчейне.

1. Открой Chrome браузер, заходи на [MetaMask официальный сайт](https://metamask.io/)
2. Кликни **"Download"**, установи Chrome расширение
3. После установки кликни на логотип лиса MetaMask в правом верхнем углу браузера
4. Выбери **"Create a new wallet"**, установи пароль
5. **ВАЖНО**: сохрани 12 слов-напоминания (мnemonic words). На тестовой сети не критично, но хорошая привычка важна

## 2.2 Переключиться на Sepolia тестовую сеть

MetaMask по умолчанию подключен к основной сети Ethereum. Нам нужно переключиться на Sepolia:

1. Кликни на выпадающее меню сети в верхней части MetaMask (по умолчанию показывает "Ethereum Mainnet")
2. Кликни **"Show test networks"** (показать тестовые сети)
3. Выбери **"Sepolia test network"**

Если не видишь Sepolia, кликни **"Add network"**, вручную добавь:

| Параметр | Значение |
|---------|---------|
| Network Name | Sepolia test network |
| RPC URL | `https://rpc.sepolia.org` |
| Chain ID | 11155111 |
| Currency Symbol | SepoliaETH |
| Block Explorer | `https://sepolia.etherscan.io` |

## 2.3 Получить бесплатные тестовые ETH

Развёртывание контракта и отчеканивание NFT требуют платежей Gas (комиссии за транзакции). На тестовой сети платишь тестовыми ETH, полностью бесплатно.

Посети любой из следующих кранов (Faucet) для получения бесплатных Sepolia ETH:

| Кран | Адрес | Количество за раз | Требует логин |
|-----|-------|----------|----------|
| QuickNode | `https://faucet.quicknode.com/ethereum/sepolia` | 0.1 ETH | Да |
| Alchemy | `https://www.alchemy.com/faucets/ethereum-sepolia` | 0.1 ETH | Да |
| Google Cloud | `https://cloud.google.com/application/web3/faucet/ethereum/sepolia` | 0.05 ETH | Требует Google аккаунт |

> **Совет**: 0.1 ETH хватит чтобы развернуть контракт + отчеканить десятки NFT. Если один кран не работает, попробуй другой.

После получения вернись к MetaMask, ты увидишь баланс измениться с 0 на 0.1 ETH (может потребоваться несколько секунд).

# Глава 3: Написать и развернуть смарт-контракт NFT (4 минуты)

## 3.1 Открыть Remix IDE

Remix — это официально рекомендуемое IDE для разработки смарт-контрактов Ethereum, полностью в браузере, не требует установки.

Открой браузер и заходи: **https://remix.ethereum.org/**

Ты видишь интерфейс как VS Code — слева файловый менеджер, в центре редактор кода, справа панель компиляции и развёртывания.

## 3.2 Создать файл контракта

1. В левой части кликни папку **"contracts"**
2. Кликни кнопку **"+"** в верхней части для создания нового файла
3. Назови файл **`MySimpleNFT.sol`**
4. Вставь следующий код:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

// Импортируй официальный шаблон ERC721 от OpenZeppelin
import "@openzeppelin/contracts/token/ERC721/ERC721.sol";

// Самый простой NFT контракт: только имя, символ, функция отчеканивания
contract MySimpleNFT is ERC721 {
    uint256 private _tokenId;

    // Инициализируй имя и символ NFT коллекции
    constructor() ERC721("VibeCoder", "VIBE") {}

    // Отчеканить NFT: вызови и дай текущему адресу один NFT
    function mint() public {
        _safeMint(msg.sender, _tokenId);
        _tokenId++;
    }
}
```

**Объяснение кода (меньше 15 строк, каждая понятна):**

| Код | Смысл |
|-----|-------|
| `pragma solidity ^0.8.20` | Укажи версию компилятора Solidity |
| `import "@openzeppelin/..."` | Импортируй официальный шаблон ERC721 от OpenZeppelin (это прошло проверку безопасности) |
| `contract MySimpleNFT is ERC721` | Создай контракт наследующий стандарт ERC721 |
| `ERC721("VibeCoder", "VIBE")` | Имя коллекции NFT "VibeCoder", символ "VIBE" |
| `_safeMint(msg.sender, _tokenId)` | Отчеканивай новый NFT текущему адресу |
| `_tokenId++` | Каждое отчеканивание, номер +1 |

> **Что такое ERC721?** Это стандартный протокол NFT на Ethereum, определяет базовые функции NFT (передача, просмотр владельца и т.д.). OpenZeppelin обеспечивает офици проверенную реализацию, мы просто наследуем и используем.

## 3.3 Компилировать контракт

1. Кликни на левой панели **"Solidity Compiler"** (иконка молотка)
2. Версия компилятора выбери **0.8.20** (или выше 0.8.x)
3. Кликни **"Compile MySimpleNFT.sol"**
4. Если видишь зелёную галку ✅, компиляция удалась

> Если ошибка, проверь версию Solidity совпадает и импорт OpenZeppelin правильный. Remix автоматически скачивает OpenZeppelin зависимости из npm.

## 3.4 Развернуть контракт на Sepolia

1. Кликни левой панели **"Deploy & Run Transactions"** (иконка Ethereum)
2. **Environment** выбери **"Injected Provider - MetaMask"**
   - Автоматически подключится твой кошелёк MetaMask
   - MetaMask всплывёт запрос подключения, кликни **"Connect"**
3. Убедись сеть показывает **Sepolia (11155111)**
4. Contract выпадающее меню выбери **MySimpleNFT**
5. Кликни кнопку **"Deploy"**
6. MetaMask всплывёт подтверждение транзакции, кликни **"Confirm"** (Gas очень дешёвый на тестовой сети, бесплатно)

Подожди несколько секунд, развёртывание успешно, внизу в **"Deployed Contracts"** появится адрес твоего контракта. **Скопируй и сохрани этот адрес**, потом нужен будет для просмотра NFT.

# Глава 4: Отчеканить NFT и посмотреть результат (4 минуты)

## 4.1 Отчеканить первый NFT

После развёртывания, в нижней части **"Deployed Contracts"** появится панель для взаимодействия с контрактом.

1. Разверни контракт панель, найди кнопку **"mint"** (оранжевая)
2. Просто кликни **"mint"** (параметры не нужны)
3. MetaMask всплывёт подтверждение, кликни **"Confirm"**
4. Подожди несколько секунд, транзакция завершена

Поздравляю! Ты только что отчеканил NFT номер #0, он теперь принадлежит твоему кошельку.

Можешь продолжить кликать "mint" для отчеканивания большего — каждый раз номер будет автоматически +1 (#1, #2, #3……).

## 4.2 Проверить результат отчеканивания

**Способ 1: Проверить в Remix**

В контракт панели найди функцию **"balanceOf"** (синяя кнопка), введи адрес твоего кошелька, кликни вызвать. Если вернёт `1` (или количество что ты отчеканил), успешно.

Можешь также вызвать **"ownerOf"** функцию, введи `0` (Token ID), это вернёт адрес твоего кошелька — доказательство что NFT #0 принадлежит тебе.

**Способ 2: Проверить на Etherscan (рекомендуется)**

1. Заходи на [Sepolia Etherscan](https://sepolia.etherscan.io/)
2. В поле поиска вставь адрес твоего **контракта**
3. Ты увидишь страницу контракта со всеми транзакциями
4. Кликни на **"Token Tracker"** ссылку, видишь все отчеканённые NFT

На Etherscan каждая отчеканивание транзакция имеет полную запись: кто отчеканил, когда, какой Token ID — вот это мощь блокчейна "публично, прозрачно, невозможно подделать".

# Глава 5: Продвинуто — добавить картинку к NFT (опционально)

Сейчас отчеканённый NFT только имеет номер, без картинки и описания. Для полноценного NFT нам нужно использовать **IPFS** (Interplanetary File System) для хранения картинок.

## 5.1 Что такое IPFS?

IPFS — это децентрализованная сеть хранения файлов. Отличие от обычного облачного хранилища, файлы на IPFS не зависят от одного сервера, а распределены по всему миру. Это означает:

* Файлы не потеряются если какой-то сервер упадёт
* Содержимое идентифицируется хешом, его нельзя подделать
* Идеально для хранения картинок и метаданных NFT

## 5.2 Загрузить картинку на Pinata

[Pinata](https://pinata.cloud/) — самый популярный IPFS сервис, бесплатная версия даёт 1GB хранилища, хватит нам.

1. Заходи https://pinata.cloud/, зарегистрируйся свободно
2. Логинься, кликни **"Upload"** → **"File"**
3. Выбери картинку что хочешь как NFT (можно AI сгенерировать или найти картинку)
4. После загрузки успешно, скопируй **CID** файла (что-то вроде `QmXyz...` строка символов)

Адрес картинки будет: `ipfs://твой-CID`

## 5.3 Создать метаданные JSON

Метаданные NFT — это JSON файл с описанием NFT (имя, описание, картинка ссылка). Создай `metadata.json`:

```json
{
  "name": "Vibe Coder Certificate #0",
  "description": "This NFT certifies that the holder has completed the NFT minting tutorial and entered the world of Web3.",
  "image": "ipfs://твой-CID-картинки",
  "attributes": [
    { "trait_type": "Course", "value": "Easy Vibe" },
    { "trait_type": "Skill", "value": "Smart Contract" },
    { "trait_type": "Level", "value": "Beginner" }
  ]
}
```

Загрузи `metadata.json` на Pinata тоже, получи его CID.

## 5.4 Обновить контракт для поддержки картинок

Для картинок нужно обновить контракт, добавить `tokenURI` функцию. Создай новый файл `MyNFTWithImage.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";

contract MyNFTWithImage is ERC721, ERC721URIStorage {
    uint256 private _tokenId;

    constructor() ERC721("VibeCoder", "VIBE") {}

    // Отчеканить с метаданных адресом
    function mint(string memory uri) public {
        _safeMint(msg.sender, _tokenId);
        _setTokenURI(_tokenId, uri);
        _tokenId++;
    }

    // Solidity требует переопределения
    function tokenURI(uint256 tokenId)
        public view override(ERC721, ERC721URIStorage)
        returns (string memory)
    {
        return super.tokenURI(tokenId);
    }

    function supportsInterface(bytes4 interfaceId)
        public view override(ERC721, ERC721URIStorage)
        returns (bool)
    {
        return super.supportsInterface(interfaceId);
    }
}
```

Развернёшь и вызываешь `mint` с адресом метаданных (например `ipfs://QmAbc.../metadata.json`), отчеканённый NFT будет иметь картинку и описание!

Поздравляю! Ты завершил полный цикл разработки NFT. Вспомни что мы сделали:

1. Понял что такое NFT и смарт-контракты
2. Установил MetaMask кошелёк и переключился на Sepolia тестовую сеть
3. В Remix IDE написал и развернул менее 15 строк NFT смарт-контракт
4. Развернул контракт на Ethereum тестовой сети
5. Отчеканил свой собственный NFT и проверил на Etherscan
6. (опционально) Научился использовать IPFS для добавления картинок к NFT

Весь процесс без установки локального окружения, без траты денег, полностью в браузере. Это магия разработки на блокчейне — намного проще чем ты думал.

**Направления развития:**

* **Hardhat / Foundry локальная разработка**: когда логика контракта усложняется, Remix больше не хватит. Hardhat и Foundry — профессиональные фреймворки с автоматическими тестами, развёртыванием, оптимизацией Gas
* **Белые списки и ограничения отчеканивания**: кто может отчеканивать, сколько максимум, установи цену отчеканивания
* **Фронтенд страница отчеканивания**: используй React + ethers.js для создания красивой интерфейс отчеканивания
* **Исследуй ERC1155 мультилицензионные NFT**: ERC1155 позволяет один Token ID быть несколько копиями, подходит для игровых предметов, билетов
* **Развернуть на основную сеть**: когда готово, развернуть на Ethereum основную сеть (или Polygon, Base и др. L2 сети дешевле Gas)

***Твой первый NFT уже на цепи, дверь в Web3 мир открыта.***

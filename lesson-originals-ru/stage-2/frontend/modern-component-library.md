# Обновление интерфейса с использованием современной библиотеки компонентов

В предыдущих курсах вы уже научились использовать инструменты дизайна для превращения макета в код, даже завершили полный фронтенд-проект. Но вы, вероятно, также заметили одну неловкую проблему: самостоятельно написанные с нуля кнопки, формы, модальные окна, хотя и функциональны, но всегда кажутся чем-то неуловимо отличающимися от "профессионального продукта" — стиль не совсем единообразен, интерактивные детали не достаточно гладкие, адаптивность к разным экранам очень мучительна.

Это именно проблема, которую решает **библиотека компонентов**.

Библиотека компонентов — это набор предварительно разработанных и тщательно разработанных UI элементов. Кнопки, поля ввода, раскрывающиеся меню, диалоги, таблицы... все эти элементы интерфейса, которые вы будете использовать многократно в любом продукте, библиотека компонентов уже разработала, и они прошли проверку многих пользователей. Вам нужно только, как собирать конструктор, собрать их вместе, и вы можете быстро построить профессиональный интерфейс.

## Что вы изучите

1. Разобраться, что такое библиотека компонентов и почему современная разработка почти все их используют
2. Познакомиться с четырьмя наиболее репрезентативными библиотеками компонентов и понять их сильные стороны в разных сценариях
3. Через три практических сценария (целевая страница, страница продукта, бэк-офис), научиться использовать AI IDE + библиотека компонентов для Vibe Coding
4. Научиться читать документацию библиотеки компонентов, находить подходящие компоненты в соответствии с требованиями и правильно их использовать

## 1. Зачем нужна библиотека компонентов?

Представьте, что вы ремонтируете дом. Вы можете сделать стул с нуля из дерева, но обычнее способ — купить стул в IKEA — хорошо спроектирован, качество стабильно, инструкция ясная, возьмите домой и собирайте.

Библиотека компонентов — это "IKEA" фронтенд-разработки. Не дом мебель, а интерфейс запасные части:

| Самостоятельно написать | Использовать библиотеку компонентов |
|--------|--------|
| Нужно самостоятельно обрабатывать стили, взаимодействие, анимацию | Открыть и использовать, стили и взаимодействие уже разработаны |
| Кнопки на разных страницах могут выглядеть по-разному | Глобальный стиль единообразен, автоматически единообразен |
| Адаптивность к мобильному требует дополнительной работы | Большинство библиотек компонентов уже встроен адаптивная поддержка |
| Доступность (Accessibility) легко упустить | Профессиональная библиотека компонентов уже обработана клавиатурная навигация, чтение с экрана и т.д. |
| Скорость разработки медленная | Скорость разработки быстрая, сконцентрироваться на бизнес-логике |

Просто сказано: **библиотека компонентов позволяет потратить время на "что делать", а не на "как рисовать".**

### Наглядное сравнение: с библиотекой и без

Разница больше всего видна на примере. Используем в Trae почти одинаковое требование, отдельно не указывая и указывая библиотеку компонентов, посмотрим разницу результата.

## 2. Познакомиться с четырьмя основными библиотеками компонентов

Есть много библиотек компонентов (полный список см. в [Приложение](#приложение-больше-библиотек-компонентов)), но вам нужно познакомиться сначала только с четырьмя наиболее репрезентативными:

| Библиотека | Фреймворк | Одна фраза определение | Официальный сайт |
|--------|--------|--------|--------|
| [Ant Design](https://ant.design) | React | Муравей выпускает инструменты группы, стандарт индустрии для бизнес-систем, огромное охватывание компонентов | ant.design |
| [shadcn/ui](https://ui.shadcn.com) | React | Без установки npm пакета, прямо скопировать код в проект, на основе Tailwind CSS, максимальная свобода настройки | ui.shadcn.com |
| [HeroUI](https://heroui.com) (перед этим NextUI) | React | Внешний вид по умолчанию красивый, анимация гладкая, подходит для целевых страниц и демонстрации продукта высокого качества | heroui.com |
| [Material UI](https://mui.com) | React | Самая старая библиотека React компонентов, реализация спецификации Google Material Design, экосистема самая зрелая | mui.com |

> Пользователи Vue также имеют богатые варианты: [Element Plus](https://element-plus.org) (самая популярная в стране), [Ant Design Vue](https://antdv.com), [Naive UI](https://www.naiveui.com) и т.д., см. [Приложение](#приложение-больше-библиотек-компонентов).

Разные библиотеки компонентов наиболее сильны в разных сценариях. Далее через три реальных сценария разработки показываем вам, как использовать AI IDE + библиотеку компонентов для Vibe Coding.

Чтобы показать разные стили и особенности библиотек компонентов, в каждом сценарии мы намеренно выбрали разные библиотеки. Но обратите внимание: **это только для того, чтобы дать вам больше идей**, в реальной разработке вы полностью можете использовать только вашу любимую. Например, если вам нравится стиль shadcn/ui, можете использовать его для целевой страницы, страницы продукта и бэк-офиса все нормально. Выбрать ту, которая вам нравится и удобна, выше всего важна.

## 3. Практика 1: создание целевой страницы продукта с помощью HeroUI

**Сценарий**: вы разработали AI писателя продукт, нужна красивая целевая страница для демонстрации особенности продукта и привлечения пользователя регистрации. Целевая страница нужна сильная визуальная ударность, гладкая анимация, красивая на мобильном.

**Почему HeroUI**: красивый стиль HeroUI по умолчанию, встроена гладкая переходная анимация, очень подходит для фаса-к-пользователю демонстрационной страницы.

```bash
cd ai-writer-landing
npm install
```

### 3.3 AI будет использовать ключевые компоненты

AI генерированный код будет использовать эти HeroUI компоненты:

```jsx
import {
  Navbar, NavbarBrand, NavbarContent, NavbarItem,
  Button,
  Card, CardHeader, CardBody, CardFooter,
  Divider,
  Link,
  Chip
} from '@heroui/react'
```

Каждый компонент действие:

| Компонент | Действие | Позиция на целевой странице |
|--------|--------|--------|
| `Navbar` | Верхняя полоса навигации | Самый верх страницы, зафиксирована |
| `Button` | Кнопка, поддерживает несколько вариантов и цветов | Кнопка CTA, кнопка навигации |
| `Card` | Контейнер карточки | Демонстрация особенности, карточка цены |
| `Chip` | Маленькая метка | Отметка "Рекомендуется", "Самое популярное" |
| `Divider` | Разделитель | Визуальное разделение между секциями |

## 4. Практика 2: создание страницы продукта с shadcn/ui

**Сценарий**: AI писателю нужна основная страница пользователя после входа — слева список документов, справа редактор, верху полоса инструмента. Это функциональная страница продукта, нужна высокая степень настройки UI.

**Почему shadcn/ui**: shadcn/ui кладёт код компонента прямо в ваш проект, можете любой момент изменить любой детали. Для страницы продукта требующей глубокой настройки это самый гибкий.

<!-- TODO: замена на скриншот официального сайта shadcn/ui или демонстрация компонента -->

### 4.1 Создание проекта

```bash
# Создать Next.js проект
npx create-next-app@latest ai-writer-app --typescript --tailwind --app
cd ai-writer-app

# Инициализировать shadcn/ui
npx shadcn@latest init

# По требованию добавить компоненты (не устанавливать все сразу)
npx shadcn@latest add button card input sidebar sheet dialog
```

shadcn/ui уникальное: каждый раз `add` компонент, он скопирует исходный код в папку `components/ui/` вашего проекта. Вы можете прямо открыть эти файлы и отредактировать стили и поведение.

### 4.2 Используйте AI IDE для генерации страницы продукта

```text
Пожалуйста, помогите мне сделать основную страницу AI писателя, используйте библиотеку компонентов shadcn/ui:

**Общая вёрстка:**
- Слева складная боковая панель, ширина примерно 280px:
  - Верхний нова кнопка "Создать документ"
  - Ниже список документов, каждый документ показывает заголовок и время последнего редактирования
  - Щелчок правой кнопкой мыши документ можно переименовать или удалить
- Справа основная область редактирования, разделена на верхний и нижний две части:
  - Вверху полоса инструмента: можно редактировать заголовок документа, показать количество символов, кнопка "AI продолжить письмо", раскрывающееся меню "Экспорт"
  - Вниз область редактирования: большое текстовое поле ввода, займить всё оставшееся пространство

**Детали взаимодействия:**
- После щелчка "AI продолжить", кнопка показать статус загрузки, в нижней области редактора появляться AI сгенерированный текст (как печатная машина постепенно показать)
- На мобильном боковая панель стать ящик скольжение, скользить из левой стороны
- Текущий выбранный документ выделяться
```

```tsx
import { Button } from '@/components/ui/button'

  Sidebar,
  SidebarContent,
  SidebarHeader
} from '@/components/ui/sidebar'
```

| Компонент | Действие | Позиция страницы продукта |
|--------|--------|--------|
| `Sidebar` | Складная боковая панель | Левая сторона список документов |

| `DropdownMenu` | Раскрывающееся меню | Кнопка "Экспорт", меню правой кнопки мыши |

| `Button` | Кнопка, поддерживает вариант и статус загрузки | Различные кнопки операции |
| `Input` | Поле ввода | Редактирование заголовка документа |

### 4.4 Настройка стилей компонента

shadcn/ui преимущество — можете прямо изменить исходный код компонента. Например хотите кнопку скругления побольше:

```text
Пожалуйста, помогите мне изменить файл components/ui/button.tsx,
изменить скругление всех кнопок по умолчанию из rounded-md на rounded-xl,
и для primary вариант добавить микротень эффект
```

AI будет прямо изменить файл компонента в вашем проекте, не закрывать стили npm пакета — это именно преимущество shadcn/ui "владеть кодом".

## 5. Практика 3: создание интерфейса бэк-офиса с Ant Design

**Сценарий**: AI писателю после запуска нужен управляющий бэк-офис для просмотра данных пользователя, управления содержание документа, обработка оплаты заказа. Ядро бэк-офиса система — показ данных и эффективность операции.

**Почему Ant Design**: Ant Design в области бизнес-системы имеет глубокий опыт накопления, таблица, форма, график и другие компоненты бизнес-логики открыть коробку即用, встроены много функций управления предприятием (выбор множественность, высокая фильтрация, экспорт данных и т.д.).

### 5.2 Используйте AI IDE для генерации бэк-офиса

```text
Пожалуйста, помогите мне сделать управляющий бэк-офис AI писателя, используйте библиотеку компонентов Ant Design:

**Общая вёрстка:**
- Слева меню: панель инструментов, управление пользователем, управление документом, управление заказ, установка системы
- Верхний раздвиж навигация

**Страница управления пользователем:**
- Вверху четыре карточка статистика: всего пользователей, сегодня новые, активные пользователи, оплаченные пользователи
- Поиск и фильтр область: можно по имя пользователя поиск, выбрать диапазон регистрации, фильтр статус пользователя, кнопки "Поиск" и "Переустановить"
- Таблица пользователя:
  - Показать аватар, имя пользователя, емейл, время регистрации, план подписки (используя разные цвета метки отличать), статус, операция
```

## 6. Научитесь читать документацию: "инструкция" библиотеки компонентов

Vibe Coding AI поможет вам написать большую часть кода, но когда результат сгенерированный AI неправильно или вы хотите немного отрегулировать поведение компонента какого-нибудь, **читать документацию** самый быстрый способ решить.

Возьмём Ant Design как пример, адрес документации: `https://ant.design/components/overview-cn`

Стандартное процесс чтения документации:

1. **Понять требование**: например "я нужен таблица поддерживает выбор строки"
2. **Поиск в документации**: поиск "Table" заходить на страница компонента таблица
3. **Посмотреть пример**: каждый компонент в документации много примеров для использования в сети, найти пример "selectable"
4. **Скопировать код**: скопировать исходный код пример в ваш проект
5. **Посмотреть API таблица**: в нижной части страница найти полную таблица конфигурирование атрибута `rowSelection`

> Также можете прямо дать документация ссылка AI IDE: "пожалуйста согласно https://ant.design/components/table-cn файла `rowSelection` API, помогите мне добавить множественность выбор функция для таблица пользователя". Дать AI предоставить документация ссылка, сгенерированный код более точно.

Скорость запроса документации каждой библиотеки компонентов:

| Библиотека | Адрес документации |
|--------|--------|
| Ant Design | `https://ant.design/components/overview-cn` |
| shadcn/ui | `https://ui.shadcn.com/docs/components` |
| HeroUI | `https://heroui.com/docs/components` |
| Material UI | `https://mui.com/material-ui/all-components/` |
| Element Plus | `https://element-plus.org/zh-CN/component/overview.html` |

## 7. Краткое резюме

Три практических сценария охватывают наиболее распространённые потребности разработки фронтенда:

| Сценарий | Рекомендуемая библиотека | Основная особенность |
|--------|--------|--------|
| Целевая страница / демонстрирующая страница | HeroUI | Стиль по умолчанию красивый, анимация гладкая, визуальная ударность сильная |
| Страница функция продукта | shadcn/ui | Код полностью управляемый, глубокая настройка гибкий |
| Система управления бэк-офиса | Ant Design | Компонента бизнес богаты, таблица форма откабина即用 |

Краткое резюме рабочего процесса Vibe Coding:

1. На основе сценария выбрать подходящей библиотеки компонентов
2. Используйте AI IDE описать структура страница и взаимодействие требование по естественный язык
3. AI генерировать начальный версия кода, вы предпросмотр эффект
4. По естественный язык продолжайте диалог с AI итерировать регулировка
5. Встретили детали проблемы, проверить документация библиотеки компонентов

### Практика

Выберите один из следующих сценариев, используя AI IDE + библиотеки компонентов с нуля завершить:

1. Используйте HeroUI создать демонстрирующая страница для проект который вы ранее делали (например Хогвартса портреты)
2. Используйте shadcn/ui построить основную страница приложение записи (боковой панель + редактор)
3. Используйте Ant Design построить простой управления содержание бэк-офиса (список статья + форма новой статья)
